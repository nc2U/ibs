운영비 내역 관리 ​

프로젝트 수행을 위해 별도로 운영되는 운영비 (전도금) 계좌의 입출금 내역을 기록하고, 이를 회계 계정 및 프로젝트별 계약 정보와 연결하여 관리하는 화면입니다.

  • 위치: 회계 자금 관리 › 운영비 내역 관리

📸 실제 화면 안내

▲ 회계자금관리 › 운영비내역관리 › 운영비 내역 수정 화면

개요 ​

대규모 공사비나 토지대금을 집행하는 본 사업비 계좌 (신탁/PF 계좌) 외에, 프로젝트 사업단이나 현장 사무소의 일상 경비 (여비교통비, 소모품비, 현장 식대, 일상 용역비 등) 집행을 위해 운용하는 운영비 계좌 (전도금 계좌)의 거래를 관리합니다. 등록된 거래는 회계 계정과목 및 적격 지출 증빙과 정확히 매칭되며, 본사 자금일보와 실시간 연동되어 운영비 집행의 투명성을 확보합니다.

주요 기능 ​

  • 운영비 (전도금) 전용 특화 조회: 프로젝트별로 개설된 운영 계좌를 기준으로 기간별, 비목별 지출 명세 집중 관리
  • 다수 거래 일괄 입력 지원: 영수증 정산 시 여러 건의 일상 경비 지출 내역을 한 화면에서 행 단위로 빠르게 등록
  • 인라인 다이렉트 편집 (Inline Editing): 목록 화면에서 항목을 더블 클릭하여 적요, 메모, 금액, 계정과목 등을 이동 없이 즉시 수정
  • 이체 수수료 자동 분개: 인터넷 뱅킹 이체 시 발생하는 송금 수수료 (500원) 분개를 원클릭으로 자동 생성
  • 대체 거래 (자금 이동) 자동 처리: 본사 계좌에서 운영비 통장으로 전도금을 입금받거나 계좌 간 자금 이동 시 상대측 전표 자동 생성 제안
  • 엑셀 템플릿 연동: 대량의 월간 운영비 정산 내역을 엑셀 서식으로 다운로드 및 대량 업로드 지원
  • 화면 간 하이라이트 포커싱: 자금 일보 등 외부 화면에서 특정 운영비 링크를 타고 진입 시 해당 거래 행을 자동으로 찾아 스크롤 및 강조 표시

화면 구성 및 실무 가이드 ​

1. 목록 제어 및 검색 필터 ​

특정 프로젝트의 운영비 지출 내역을 조건별로 검색하고 규모를 파악하는 영역입니다.

  • 검색 조건: 거래일자 범위, 입출금 구분 (전체/입금/출금), 계정과목 분류, 운영 계좌 선택, 관련 계약 정보 및 검색어 (적요/거래처)
  • 실시간 데이터 집계: 조회 조건에 부합하는 총 거래 건수와 지출 합계가 즉시 표시되어 월별 경비 규모를 한눈에 파악할 수 있습니다.

2. 운영비 입출금 현황 목록 ​

조회된 내역을 직관적인 테이블 형태로 표시하며, 상단의 통장 원장과 하단의 회계 분개로 구성됩니다.

  • 은행거래내역 (통장 원장): 실제 통장에 기록된 거래일자, 계좌 별칭, 통장 적요, 입금액/출금액 정보
  • 분류 내역 (회계 분개): 해당 거래의 회계 계정과목, 거래처, 분류 금액, 지출 증빙 유형 (신용카드, 세금계산서, 현금영수증 등)
  • 금액 일치 검증: 통장 입출금액과 하단 분류 내역 금액의 합계가 일치하면 **초록색 체크 (✅)**가 표시되며, 차액 발생 시 노란색 경고 행으로 부족하거나 초과된 금액을 안내합니다.

3. 거래 등록 및 수정 폼 ​

새로운 운영비 거래를 등록하거나 기존 지출 건을 수정하는 화면입니다.

  • 신규 거래 등록 (다수 건): [새 거래 등록] 버튼을 눌러 여러 건의 영수증 지출 내역을 연속해서 입력할 수 있습니다.
  • 인라인 즉시 수정: 목록에서 수정하고자 하는 셀 (적요, 메모 등)을 마우스로 더블 클릭하면 팝업 없이 즉시 텍스트를 수정할 수 있습니다.
  • 상세 수정 모달: 복잡한 계정 분할이나 지출 증빙 파일 첨부가 필요한 경우 개별 행의 수정 아이콘을 클릭하여 상세 편집창을 호출합니다.

💡 실무 활용 팁 및 관리 포인트 ​

  • 인라인 편집 시 계정 연동 팝업 주의: 목록에서 계정과목 셀을 더블 클릭하여 수정할 때, 선택한 계정이 분양 계약이나 외주 용역 계약 매칭이 필수인 계정인 경우 시스템이 자동으로 계약 선택 모달을 띄워 데이터 누락을 방지합니다.
  • 대체 거래 (전도금 수령) 처리 요령: 본사에서 현장 운영비 계좌로 500만 원의 전도금을 송금한 경우, 본사 출금 거래 등록 시 계정과목을 '대체 (출금)'으로 지정하면 현장 운영비 계좌의 '대체 (입금)' 거래를 자동으로 생성할 것인지 묻는 확인 창이 뜹니다. 이를 승인하면 양측 계좌의 자금 흐름이 자동으로 일치됩니다.
  • 소액 지출 증빙 관리: 운영비는 식대, 소모품 등 소액 카드 결제 및 간이영수증이 많습니다. [지출 증빙] 항목에서 적격 증빙 (카드, 현금영수증, 세금계산서) 구분을 정확히 지정해 두어야 부가세 매입세액 공제 신고 시 누락을 방지할 수 있습니다.
  • 과거 데이터 수정 제한 (정산 마감 보호): 최종 정산이 완료된 일자 이전의 데이터나 등록 후 10일이 경과한 거래는 임의 수정이 제한됩니다. 수정이 꼭 필요한 사유가 발생한 경우 상급 관리자에게 정산 잠금 해제를 요청해야 합니다.
