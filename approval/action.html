결재 처리 및 상신 관리 (Approval Actions) ​

📸 실제 화면 안내

관리자 참고: 해당 화면의 실제 캡처 이미지를 ./images/action.png 경로에 등록해 주세요.

결재선에 포함된 심사자는 문서를 검토한 후 승인, 반려, 또는 여러 건의 대기 문서를 한 번에 처리하는 다건 일괄 승인을 수행할 수 있으며, 기안자는 1차 승인 전까지 자유롭게 기안 회수가 가능합니다.

  • 접근 경로: 시스템 좌측 내비게이션 메뉴에서 **[전자결재 시스템] → [결재 진행 및 처리] → [승인 / 반려 / 상신 회수]**를 선택하여 접속합니다.

1. 결재 액션 결정 흐름도 ​

2. 단건 결재 승인 (Approve) ​

현재 결재 순번에 해당하는 결재자는 상세 화면 또는 대기 목록에서 문서를 승인합니다.

  • 승인 의견 입력 (선택): 승인 코멘트나 추가 당부 사항을 남길 수 있으며 결재 타임라인에 영구 기록됩니다.
  • 전자 직인 및 무결성 해시 각인: 승인 완료 시 결재 시점의 본문 데이터에 대한 보안 해시값이 스냅샷되어 사후 위변조를 원천 차단합니다.
  • 대리 결재(대결) 표기: 권한을 위임받은 대결자가 승인한 경우, 이력에 대결: 김철수 (원 결재자: 홍길동) 형태로 투명하게 명시됩니다.

📱 모바일 앱 생체인증 간편 승인

  • Face ID / 지문 인식: 스마트폰에 생체인증이 등록되어 있다면, 승인 버튼을 누르고 생체인증(Face ID 또는 지문)을 완료하는 즉시 원터치로 안전하게 승인 처리됩니다.
  • 실시간 푸시 알림 승인: 외부 이동 중 결재 요청 푸시 알림이 도착했을 때, 알림을 탭하면 결재 상세 화면으로 바로 이동하여 즉시 검토하고 승인할 수 있습니다.

3. 다건 일괄 승인 (Batch Approve) ​

반복적이고 정형화된 결재 건(지출결의서, 영수증 증빙, 정기 휴가원 등)이 다수 밀려있을 때 고속 처리를 지원합니다.

  • 웹 (PC) 환경 실행 방법:
    1. 결재 대기함 목록에서 상단 전체 선택 또는 개별 체크박스를 클릭합니다.
    2. 상단 액션바에 활성화되는 [선택 문서 일괄 승인 (N건)] 버튼을 클릭합니다.
    3. 확인 팝업창에서 대상 문서 목록(제목, 유형, 기안자)을 확인하고, 필요시 공통 결재 의견을 입력합니다.
    4. [일괄 승인 실행] 버튼을 누르면 실시간 진행률 표시와 함께 순차적으로 승인 처리가 완료됩니다.
  • 모바일 앱 환경 실행 방법:
    1. 대기함 상단의 체크 아이콘을 눌러 '선택 모드'로 전환합니다.
    2. 대기 카드를 복수 선택한 후 하단 [일괄 승인] 버튼을 누릅니다. (생체인증 1회 확인 후 자동 순차 승인)

안전 권고사항: 계약서 초안이나 대규모 투자 안건 등 법적·재무적 검토가 필요한 문서는 일괄 승인에서 제외하고, 반드시 상세 화면에서 내용을 면밀히 확인한 후 개별 승인하십시오.

4. 결재 반려 (Reject) ​

문서의 내용에 오류가 있거나 보완이 필요한 경우 결재를 기각합니다.

  • 반려 사유(의견) 필수 입력: 기안자가 원인을 명확히 파악할 수 있도록 반려 사유 입력을 필수로 강제합니다.
  • 결재선 즉시 중단: 반려 즉시 후속 결재 단계는 모두 취소되며, 문서 상태가 반려로 전환됩니다.
  • 기안자 알림 & 재상신: 기안자에게 즉시 반려 알림이 발송되며, 기안자는 반려된 문서를 기반으로 내용을 보완하여 새 문서로 재상신할 수 있습니다.

5. 기안 회수 (Cancel Submission) ​

기안자가 상신 후 오탈자를 발견했거나 급히 첨부 서류를 변경해야 할 때 결재를 취소하는 기능입니다.

구분회수 가능 상태회수 불가 상태
조건1단계 결재자가 승인/반려하기 전1단계 결재자가 이미 승인 완료했거나 최종 승인된 경우
처리 방법문서 상세 화면에서 [기안 회수] 버튼 클릭결재권자에게 구두 연락하여 '반려' 처리 요청
문서 상태기존 결재선 초기화 → 임시저장 복귀기존 결재 단계 유지
후속 조치내용을 자유롭게 수정하거나 첨부파일을 변경 후 재상신반려 완료 후 문서를 재작성하여 상신

6. 최종 승인 완료 시 자동 처리 ​

최종 결재권자가 승인을 완료하면 시스템에서 아래 3대 작업이 자동으로 처리됩니다.

  1. 공식 문서 번호 자동 발급: 사내 채번 규정에 따라 중복 없는 고유 번호(예: BIZ-2026-0001)가 즉시 발급됩니다.
  2. 전자 직인 A4 PDF 생성: 회사 직인, 기안자 정보, 결재자 서명 타임라인이 각인된 공식 PDF가 시스템에 자동 생성 및 영구 보관됩니다.
  3. 기안자 및 참조자(공람) 알림: 기안자에게 최종 승인 알림이 발송되며, 지정된 참조자에게 공람 안내가 즉시 전달됩니다.

7. 신입사원 실무 팁: 기안이 반려되었을 때 대처법 ​

  • 반려 사유 확인: 문서 상세 화면 하단의 결재 타임라인에서 결재권자가 남긴 '반려 사유'를 꼼꼼히 확인합니다.
  • 복사 재기안 기능 활용: 반려된 문서를 처음부터 다시 쓸 필요 없이, 문서 상세 화면 우측 상단의 [복사하여 재기안] 버튼을 누르면 기존 내용과 첨부파일이 그대로 복사된 새 기안 작성 창이 열립니다. 지적된 사항만 수정한 후 손쉽게 재상신하세요.
