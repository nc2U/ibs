## 2. 영역별 상세 품질 평가

### ① 비즈니스 도메인 적합성 (A+)
- **행정안전부 공문서 서식 완벽 준용**:
  - 두문(로고/회사명), 본문(수신/경유/참조/제목/내용/붙임), 결문(발신명의/직인날인), 하단 메타(시행/접수/우편/전화/팩스/이메일/공개구분) 4단 구조 체계 완성.
- **문서번호 자동 채번 체계**:
  - `{회사단축명}-{연도}-{순번}` 체계로 연도별 단조 증가 시퀀스 보장.
- **붙임(첨부) 처리 이원화**:
  - 실제 파일 업로드(PDF, 이미지, 문서)와 출력 전용 붙임 텍스트(`1. 사업계획서 1부. 끝.`)를 유연하게 지원.

### ② 데이터 정합성 및 법적 효력 통제 (A+)
- **시행일자(발신일)의 지능적 확정 로직 (`effective_issue_date`)**:
  - 기안 시점의 `issue_date`는 "발신 요청일"로 취급.
  - 전자결재 연동 시 결재 완료일(`completed_at`)이 요청일보다 늦어지더라도 실제 승인일에 맞춰 공문서 시행일자가 법적으로 자동 보정 확정.
  - 대외 발송 완료 시 `dispatched_at` 일자로 최종 영구 동결.
- **직인(인감) 보안 및 전결 규정 연동**:
  - 법인인감, 사용인감, 직인생략 지원 및 각 인감에 설정된 전결 직위(`final_approval_duty_name`) 검증.
- **공개 구분(1: 공개, 2: 부분공개, 3: 비공개) 법적 보호 장치**:
  - 행정기관 및 외부 기관 대상 공문 발송 시 정보공개법 및 개인정보보호법/부정경쟁방지법(영업비밀)에 따른 면책 및 보호 기준 마련.

### ③ PDF 렌더링 & 서식 일관성 (A)
- **CSS Paged Media 규격 준수**:
  - `@page { size: A4 portrait; margin: 20mm 20mm 15mm 20mm; }`
- **결재선과 메타 테이블의 통합 칼정렬**:
  - 기존의 분리되어 있던 결재선 블록을 메타 테이블 1행에 배치하여 하단 메타 테이블(시행/접수/우편/전화)과 수직 라인이 1px의 어긋남 없이 정렬.
- **직인 투명 합성**:
  - 회사 발신명의 우측에 원형 40~50px 규격으로 직인 이미지를 정확한 위치에 자동 오버레이 날인.

### ④ 프론트엔드 UX / UI (A)
- **WYSIWYG 실시간 반응형 프리뷰 (Live A4 Preview)**:
  - 좌측에서 제목, 내용, 붙임, 직인, 공개구분을 변경하면 우측 A4 공문 양식에 실시간 동기화.
- **실수 방지 가드레일 (Safety Guardrails)**:
  - 공개구분 선택 시 영업비밀/개인정보 주의 안내 실시간 경고 출력.
  - 발송 완료된 공문서의 경우 PDF 재생성 차단 및 위변조 방지 경고.
  - 전자결재 모드와 직접(수동) 발송 모드 간의 명확한 UI 분기.

## 3. 타 엔터프라이즈 전자결재/공문 솔루션 대비 강점

1. **독립 모듈이 아닌 전사 ERP/업무(Work) 생태계와의 결합**:
   - 프로젝트, 회사, 부서, 인사(Staff), 전자결재(Approval) 테이블과 외래키로 긴밀하게 결합되어 있어 별도의 수동 입력 없이 결재자 직위/성명/연락처가 100% 공식 데이터로 자동 전파.
2. **사후 발송 이력 관리(대장 관리) 내장**:
   - 단순 문서 생성을 넘어 등기번호 추적, 발송방법(이메일/등기/퀵/인편), 수신지 라벨 출력 연계가 가능하여 총무/공무팀의 발송 대장 업무를 완전 전산화.
3. **무결성 및 불변성(Immutability) 보장**:
   - 발송 완료 시점 이후에는 임의 수정이 차단되며, 실물 날인 스캔본 업로드 이력 관리 지원.
