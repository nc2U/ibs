우편 라벨 관리 ​

프로젝트 계약자들의 주소 정보를 바탕으로 규격 라벨지에 인쇄할 수 있도록 라벨 데이터를 생성하고 출력하는 페이지입니다.

  • 위치: 고객 고지 관리 > 우편 라벨 관리

개요 ​

고지서, 안내문, 총회 책자 등의 우편물 발송 시 필요한 수신처 라벨 스티커를 표준 폼텍(Formtec) 라벨지 규격에 맞춰 손쉽게 출력할 수 있습니다. 차수, 타입, 동별 필터링은 물론, 우편송부지 및 주민등록지 기준 선택, 라벨지 내 인쇄 시작 위치 지정, 수신자 맞춤 인쇄 옵션 등을 제공합니다.

주요 기능 ​

  • 표준 라벨 규격 지원: 한국폼텍 표준 라벨지(Formtec 3107 - 16칸, 2열 8행) 기본 지원
  • 시작 위치 오프셋(인쇄 시작 칸) 지정: 이미 일부 사용한 라벨지를 재활용할 수 있도록 첫 번째 라벨 인쇄 위치(1번~16번) 지정 가능
  • 주소지 선택 기준 지원:
    • 우편송부지 우선: 우편송부지가 등록되어 있으면 우편송부지를, 없으면 주민등록상 주소를 적용
    • 우편송부지 전용: 우편송부지가 등록된 계약자만 주소 출력
    • 주민등록지 전용: 우편송부지와 관계없이 계약자의 주민등록상 기본 주소 출력
  • 다양한 인쇄 옵션 토글: 우편번호 바코드 출력 여부, 계약자명 '귀하' 존칭 표시 여부, 계약 동호수(또는 일련번호) 표기 여부 설정
  • 대량 데이터 최적화 페이징 및 선택 제어: 수천 명의 계약자 데이터를 쾌적하게 조회할 수 있도록 페이지당 표시 개수(30/50/100/200개) 설정, 현재 페이지 전체 선택 및 검색된 전체 계약자 일괄 선택 기능 지원
  • 브라우저 1:1 표준 규격 인쇄: 라벨 규격에 최적화된 CSS 미디어 쿼리(@media print)를 적용하여 별도의 외부 소프트웨어 없이 브라우저 인쇄(Ctrl+P / Cmd+P)로 실물 라벨지에 오차 없이 출력

화면 구성 ​

1. 필터 및 인쇄 환경 설정 (상단) ​

라벨을 출력할 대상 조건과 라벨 용지 출력 옵션을 지정합니다.

주요 설정 항목 ​

항목구분설명
차수 / 타입 / 동필터특정 차수, 유닛 타입, 동별로 계약자를 선별
라벨 규격인쇄 설정출력할 라벨지 제품 규격 선택 (Formtec 3107: 99.1 × 38.1 mm, A4당 16칸)
인쇄 시작 위치인쇄 설정라벨지 내 첫 번째 데이터가 인쇄될 칸 번호 지정 (1~16번). 사용하다 남은 라벨 용지 활용 시 유용
주소지 선택데이터 기준우편송부지 우선, 우편송부지 전용, 주민등록지 전용 중 선택
바코드 표시인쇄 옵션우편번호(5자리) 영문 바코드 서식 표시 여부
'귀하' 표시인쇄 옵션수신자 성명 뒤 존칭('귀하') 출력 여부
동·호수 표시인쇄 옵션라벨 우측 상단에 계약 동·호수(미지정 시 일련번호) 표시 여부

2. 계약자 목록 및 선택 (데이터 테이블) ​

조건에 맞게 조회된 계약자 목록을 확인하고 실제 라벨로 인쇄할 대상자를 선택합니다.

  • 테이블 정보: 선택 체크박스, 일련번호, 계약자명, 동호수, 우편번호, 주소 및 상세주소, 비고(우편송부지 여부 등)
  • 페이징 제어: 하단 페이지네이션을 통해 대용량 데이터도 끊김 없이 부드럽게 탐색 가능 (페이지당 30, 50, 100, 200개 보기)
  • 선택 기능:
    • 현재 페이지 선택: 테이블 헤더의 체크박스를 클릭하여 현재 화면에 보이는 계약자만 선택
    • 검색 전체 선택: 상단의 '검색 결과 전체 선택' 버튼을 통해 조건에 일치하는 전체 대상자를 한 번에 인쇄 대상으로 지정

3. 인쇄 미리보기 및 라벨 출력 ​

출력 전 라벨 배치를 눈으로 직접 확인하고 인쇄를 실행합니다.

  • 인쇄 미리보기 버튼: 현재 선택된 계약자 수와 인쇄 시작 위치가 반영된 실물 비율의 라벨지 미리보기 모달을 호출합니다.
  • 라벨 출력 (Ctrl+P / Cmd+P): [라벨 인쇄] 버튼을 누르면 브라우저의 표준 인쇄 대화상자가 열립니다.

💡 인쇄 시 권장 설정 및 업무 팁 ​

  • 브라우저 인쇄 배율 설정: 라벨지 출력 시 브라우저 인쇄 설정에서 **'배율(Scale)'은 반드시 100%(기본값)**으로 설정하고, **'여백(Margins)'은 없음(None)**으로 지정해야 라벨지 칼선과 밀림 없이 정확하게 일치합니다.
  • 머리글/바닥글 해제: 브라우저 인쇄 창의 기타 설정에서 '머리글 및 바닥글' 체크를 해제해야 상하단에 웹페이지 URL이나 날짜가 출력되지 않고 깔끔하게 라벨지만 인쇄됩니다.
  • 남은 라벨지 절약: 이전 작업 후 몇 칸만 비어 있는 라벨지가 있다면, **'인쇄 시작 위치'**를 해당 비어있는 다음 번호(예: 5번째 칸)로 지정하여 용지 낭비 없이 알뜰하게 사용할 수 있습니다.
  • 우편번호 정합성 확인: 수신 주소에 우편번호가 등록되어 있지 않은 계약자는 라벨 하단에 주소만 표기되므로, 우편물 발송 전 계약 관리 메뉴에서 우편번호가 누락되지 않았는지 점검하는 것을 권장합니다.
