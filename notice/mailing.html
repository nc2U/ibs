MAIL 발송 관리 ​

프로젝트 계약자 또는 임의의 외부 수신자에게 공식 안내문, 소식지, 분담금 납부 안내 등을 대량 이메일(HTML)로 발송하고 그 이력을 추적·관리하는 페이지입니다.

  • 위치: 고객 고지 관리 > MAIL 발송 관리

개요 ​

SMS/LMS의 글자 수 한계와 비용 부담을 보완하여, 서식과 이미지가 포함된 완성도 높은 안내문을 이메일로 대량 발송할 수 있습니다. 위지윅(WYSIWYG) 리치 텍스트 에디터, 계약자 정보 자동 치환 태그, 수신 대상자별 이메일 직접 수정 및 외부 수신자 수기 추가, Celery 비동기 큐 기반의 안정적인 대량 발송, 그리고 상세 발송 결과(성공/실패 내역) 조회를 지원합니다.

주요 기능 ​

  • 타깃 필터링 및 수신자 자동 추출: 프로젝트 내 특정 차수 또는 동을 지정하여 계약자 이메일 목록을 즉시 조회
  • 수신 대상자 정밀 관리:
    • 이메일 미등록 계약자 확인 및 인라인 이메일 주소 등록/수정
    • 개별 수신자 발송 대상 포함/제외 토글
    • 은행, 신탁사, 시공사 등 외부 관계자 이메일 수기 추가 기능
  • 위지윅(WYSIWYG) HTML 에디터 내장: 제목, 본문 글자 스타일(크기, 굵기, 색상, 정렬 등), 인용구, 목록, 링크 및 이미지 첨부 지원
  • 동적 머지 태그(Merge Tags) 치환: , , 등 예약어를 작성하여 계약자별 맞춤 안내문 자동 생성
  • 비동기 대량 발송(Celery Worker): 수백·수천 건의 메일 발송 시에도 화면 멈춤 없이 백그라운드 워커를 통해 신속하고 안정적으로 순차 전송
  • 발송 이력 대장 및 전송 결과 상세 조회:
    • 발송 일시, 발송자, 제목, 총 대상자 수, 성공/실패 건수 실시간 집계
    • 발송 상세 모달: 서식 적용 본문 렌더링 미리보기, HTML 원문 코드 확인, 수신자별 전송 성공 여부 및 실패 원인(오류 로그) 확인

화면 구성 ​

상단 탭을 통해 **[MAIL 발송]**과 [발송 내역] 화면으로 전환할 수 있습니다.

1. MAIL 발송 (탭) ​

메일 수신 대상자를 선정하고 본문 서식을 작성하여 발송하는 화면입니다.

① 발송 기본 정보 및 수신자 설정 ​

항목설명
차수 / 동 선택메일을 발송할 대상 차수 및 동을 필터링하여 계약자를 추출합니다.
수신 대상자 관리 버튼추출된 계약자 명단 모달을 열어 이메일 주소를 확인·수정하거나 제외할 대상자를 선택합니다.
발송자 (From)시스템 로그인 사용자의 이메일 주소 및 이름으로 발송자 정보가 구성됩니다. (Django 메일 설정 기반)
안내 메일 제목이메일 수신함에 노출될 메일 제목을 입력합니다.

② 본문 작성 (Quill 에디터) 및 치환 태그 ​

  • 서식 도구함: 폰트 크기, 헤딩(H1~H3), 굵게, 밑줄, 글자색/배경색, 텍스트 정렬, 번호 목록, 하이퍼링크, 이미지 첨부 등 제공
  • 머지 태그(치환 변수) 안내:
    • {{ 계약자명 }}: 수신 계약자의 실제 성명으로 자동 변환
    • {{ 동호수 }}: 해당 계약자의 동·호수(배치 전일 경우 일련번호)로 자동 변환
    • {{ 프로젝트명 }}: 현재 선택된 사업지 명칭으로 자동 변환

③ 수신 대상자 관리 모달 ​

[수신 대상자 확인] 버튼을 누르면 열리는 팝업창으로, 실제 메일을 수신할 명단을 점검합니다.

  • 이메일 주소 즉시 수정: 등록된 이메일이 없거나 주소가 변경된 경우, 테이블 내에서 직접 입력하여 즉시 임시 반영할 수 있습니다.
  • 체크박스 선택/해제: 특정 계약자를 이번 발송에서 제외하려면 체크를 해제합니다.
  • 외부 수신자 직접 추가: 상단의 [수신자 추가] 영역에서 성명, 이메일, 비고를 입력하여 계약자 명단 외의 관계자를 수신인에 포함할 수 있습니다.

2. 발송 내역 (탭) ​

지금까지 발송된 모든 이메일의 기록을 조회하고 결과를 점검합니다.

  • 발송 이력 목록:
    • 발송일시: 메일 발송이 접수/처리된 일시
    • 프로젝트 및 발송자: 메일을 발송한 프로젝트와 로그인 사용자명(계정)
    • 제목: 발송된 이메일 제목
    • 전송 통계: 총 발송 대상 수, 성공 건수, 실패 건수를 배지로 직관적 표시
    • 상세보기: [상세보기] 버튼 클릭 시 발송 상세 모달 호출
  • 발송 상세 모달:
    • 발송 정보 요약: 프로젝트, 발송자, 발송일시, 최종 성공/실패 현황
    • 발송 본문 확인: 실제 발송된 HTML 서식 렌더링 미리보기를 제공하며, 머지 태그가 강조 표시됩니다. 필요시 [HTML 코드 보기] 토글을 통해 원문 소스 확인 가능
    • 수신자별 전송 결과 테이블: 수신자명, 이메일 주소, 전송 상태(성공/실패), 오류 발생 시 상세 사유(예: 유효하지 않은 주소, SMTP 거부 등) 기록 제공

💡 업무 팁 및 주의 사항 ​

  • 발송 전 테스트 권장: 대량 메일을 전송하기 전에 수신 대상자 관리에서 본인(담당자)의 이메일을 수기 추가한 후 1건만 시험 발송하여, 수신함에서 레이아웃과 서식, 이미지가 깨지지 않는지 먼저 확인하세요.
  • 수신자 이메일 정합성: 형식에 맞지 않는 이메일 주소(공백 포함, @ 누락 등)는 발송 실패의 주원인이 되므로 대상자 관리 팝업에서 이메일 형식을 미리 점검하세요.
  • 스팸 분류 방지: 메일 본문에 과도한 대용량 이미지 링크나 자극적인 광고성 문구가 포함될 경우 수신 측 메일 서버(Gmail, Naver 등)에서 스팸으로 분류될 수 있으므로 권장 규격에 맞게 작성합니다.
  • 치환 태그 표기 주의: 머지 태그는 공백을 포함하여 {{ 계약자명 }}, {{ 동호수 }}, {{ 프로젝트명 }} 형태로 중괄호 2개를 정확히 닫아주어야 치환 엔진이 올바르게 인식합니다.
