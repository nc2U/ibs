# 동호 배치 현황 (조감 그리드)

::: tip 📸 실제 화면 안내
![동호수 배치도 및 분양 현황 화면](./images/status.png)
*관리자 참고: 해당 화면의 실제 캡처 이미지를 `./images/status.png` 경로에 등록해 주세요.*
:::

> **동호 배치 현황** 페이지는 프로젝트의 각 동(건물)별, 층별, 라인별 유닛의 분양 진행 상태(공실, 청약, 계약, 홀딩)를 색상 블록으로 시각화하여 한눈에 조망하고, 원클릭으로 계약 상세 정보를 조회하는 분양 종합 현황판입니다.

* **접근 경로**: 시스템 좌측 내비게이션 메뉴에서 **[PJT 관리 시스템] → [계약 정보 관리] → [동호 배치 현황]**을 선택하여 접속합니다.

## 1. 주요 기능 및 시각화 특징

* **실시간 동호수 배치도 (Visual Grid)**: 아파트나 오피스텔의 실제 건축 입면과 동일하게 층별·라인별 유닛 블록을 한 화면에 렌더링
* **유닛 4대 상태 색상 구분**: 공실(미분양), 청약(가계약), 계약(본계약), 홀딩(분양제한)을 직관적인 색상으로 표출
* **타입별 전용 색상 테두리**: [타입 정보 등록](/project/types)에서 지정한 색상 코드가 유닛 상단 라벨에 반영되어 평형 분포를 한눈에 식별
* **개인정보 보호를 위한 계약자명 표시/숨김 토글**: 대외 모니터나 고객 상담용 화면으로 활용 시 원클릭으로 고객 이름을 가릴 수 있는 안심 기능
* **원클릭 계약 상세 연동**: 계약된 유닛 블록을 클릭하면 해당 계약자의 [계약 상세 관리](/contract/details) 화면으로 즉시 이동
* **동호수 현황표 엑셀 출력**: 전체 동호수 배치 현황을 엑셀 서식으로 다운로드하여 분양 보고서에 활용

## 2. 화면 구성 및 색상 범례

### 1. 계약 현황 종합 요약 카드
프로젝트 전체의 분양 실적을 실시간 집계하여 표출합니다.
* **표시 항목**: 총 세대수, 청약 세대수, 본계약 세대수, 동호 미배정 세대수, 홀딩 세대수, 잔여 세대수(공실), 총 분양률(%)
* **타입별 색상 범례**: 각 평형 타입(예: 59A, 84B)에 지정된 고유 색상 견본 표출

### 2. 동(건물)별 동호수 배치도 그리드

| 유닛 상태 | 시각적 표시 기준 | 실무적 의미 |
|:---|:---:|:---|
| **공실 (미분양)** | **배경색 없음 (화이트)** | 즉시 신규 청약 및 계약 체결이 가능한 빈 세대 |
| **청약 (가계약)** | **연한 노란색 블록** | 청약금만 납부되고 본계약 체결을 대기 중인 세대 |
| **계약 (본계약)** | **연한 회색 / 청색 블록** | 정식 분양 계약이 완료되어 수납이 진행 중인 세대 |
| **홀딩 (분양제한)**| **진한 회색 / 자물쇠 아이콘** | 회사보유분, 펜트하우스 등 분양이 일시 제한된 세대 (마우스 오버 시 홀딩 사유 툴팁 표시) |
| **필로티 (공간)** | **빗금 패턴 / 연회색** | 주거 세대가 없는 1~2층 필로티 또는 주민공동시설 층 |

## 3. 화면 제어 도구

* **계약자명 표시 토글 스위치**:
  * 스위치를 켜면 각 유닛 블록 내에 `101호 [홍길동]` 형태로 계약자 성명이 표출됩니다.
  * 스위치를 끄면 `101호`만 표출되어 분양 상담 시 내방 고객에게 개인정보 유출 없이 잔여 세대 현황을 보여줄 수 있습니다.
* **엑셀 다운로드 버튼**:
  * 현재 배치도 상태 그대로 층별·라인별 그리드 레이아웃의 엑셀 파일을 다운로드합니다.

## 4. 신입사원을 위한 실무 가이드

* **💡 모델하우스 고객 상담 시 활용법**:
  * 고객이 "어느 동 어느 층이 남아있나요?"라고 문의할 때, 본 화면에서 **'계약자명 표시'를 끈 상태**로 태블릿이나 모니터를 고객에게 보여주며 하얀색(공실) 세대를 안내하면 매우 전문적이고 직관적인 상담이 가능합니다.
* **💡 유닛 클릭을 통한 원클릭 고객 응대**:
  * 특정 호실에 대해 문의가 들어왔을 때 배치도의 해당 호수를 클릭하면, 즉시 [계약 상세 관리]로 넘어가 해당 고객의 계약일자, 납부 회차, 담당 상담사를 즉시 확인할 수 있습니다.
