# 수수료 지급 관리

확정된 정산 내역을 바탕으로 금융 이체 승인, 기업 인터넷 뱅킹 대량 이체 파일(CSV) 다운로드, 지급 완료 및 보류 처리를 일괄/개별 관리하는 페이지입니다.

- **위치**: `PJT 관리 시스템 > 분양 대행 관리 > 수수료 지급 관리`

## 개요

정산이 확정된 수수료에 대해 자금 집행을 총괄하는 화면입니다. 전체 실지급액과 현재까지의 이체 완료액 및 진척률을 실시간으로 모니터링하고, 다음 달 10일 세무 신고를 위한 **원천세 예수금 합계(3.3%)**를 사전에 파악할 수 있습니다. 또한 기업 뱅킹 사이트에 업로드할 수 있는 대량 이체용 CSV 파일을 생성 및 다운로드하고, 이체 완료 상태를 일괄 처리할 수 있습니다.

## 주요 기능

- **지급 진행 현황 대시보드 (`PayoutStatusSummary`)**:
  - 총 실지급 대상액 (세후) 및 대상 인원수
  - 지급 완료액 및 이체 완료율 (%)
  - 지급 잔액 (대기 및 보류 금액)
  - 익월 10일 세무서 및 구청 신고 납부 대상 **원천세 예수금 합계 (3.3%)**
- **회차 및 상태별 필터링**: 정산 회차 선택, 지급 상태(지급대기/승인/완료/보류) 필터, 성명/계좌 키워드 검색
- **다중 선택 기반 일괄 상태 변경**: 체크박스로 여러 명을 선택하여 `[선택 승인]`, `[선택 지급완료]`, `[선택 지급보류]` 원클릭 처리
- **기업 인터넷 뱅킹 대량 이체용 CSV 다운로드**:
  - `UTF-8 BOM`(`\uFEFF`) 인코딩 적용으로 엑셀 열람 시 한글 깨짐 원천 방지
  - 긴 계좌번호 지수 표기(예: `1.23E+11`) 방지 탭 서식 적용
  - 선택 항목 또는 현재 조회 목록 전체 다운로드 지원
- **개별 상태 변경 드롭다운**: 행별로 지급 상태를 즉시 변경 가능하며, `지급완료` 선택 시 지급일자 자동 기록

## 화면 구성

### 1. 회차 선택 및 필터 툴바

- **정산 회차 선택**: 지급을 진행할 정산 회차 선택
- **지급 상태 필터**: 전체 상태, 지급대기(1), 지급승인(2), 지급완료(3), 지급보류(4)
- **통합 검색창**: 성명, 소속 팀, 예금주, 계좌번호로 실시간 필터링
- **조회 건수 표출**: 필터 조건에 해당하는 인원수 표시

### 2. 지급 진행 현황 대시보드 (요약 카드)

- **총 실지급 대상액 (세후)**: 이번 회차에 집행되어야 할 총 이체 대상 금액
- **지급 완료액 (이체완료)**: 이미 지급 완료 처리된 금액과 전체 대비 진척률(%)
- **지급 잔액 (대기/보류)**: 아직 이체되지 않고 남아있는 잔액과 대기 인원수
- **원천세 예수금 합계 (3.3%)**: 회사가 원천징수하여 익월 10일에 국세청(소득세 3%) 및 지자체(지방소득세 0.3%)에 납부해야 할 세액 총액

### 3. 일괄 작업 및 이체 파일 다운로드 액션 바

- **전체 선택 체크박스**: 현재 필터링된 모든 항목을 일괄 선택 또는 해제
- **선택 정보 뱃지**: 현재 선택된 인원수와 실지급 합계 금액 실시간 계산
- **일괄 변경 버튼군**:
  - `[선택 승인]`: 선택된 인력들의 상태를 `지급승인`으로 일괄 변경
  - `[선택 지급완료]`: 선택된 인력들의 상태를 `지급완료`로 변경하고 오늘 일자를 지급일로 자동 기록
  - `[선택 지급보류]`: 특이사항이나 계좌 오류 등으로 이체를 보류할 때 일괄 지정
  - `[선택 해제]`: 선택 상태 초기화
- **[은행 이체용 CSV 다운로드] 버튼**: 기업 뱅킹 이체 표준 규격에 맞춘 CSV 파일 다운로드

### 4. 지급 명세 테이블

| 항목 | 설명 |
|:---|:---|
| **선택 체크박스** | 일괄 상태 변경 또는 선별 이체 다운로드를 위한 체크박스 |
| **소속 팀 / 직책 / 성명** | 영업 인력의 인적 정보 |
| **은행명 / 계좌번호 / 예금주** | 수수료가 입금될 금융 계좌 정보 |
| **총액 (세전)** | 정산된 세전 총액 |
| **원천세 (3.3%)** | 공제되는 원천징수 세액 |
| **실지급액 (세후)** | 통장에 실제 입금될 금액 (테이블 강조 표시) |
| **지급 상태** | 드롭다운 셀렉터로 즉시 상태 변경 가능 (`지급대기`, `지급승인`, `지급완료`, `지급보류`) |
| **상세** | `[내역]` 버튼 클릭 시 개인별 상세 계약 내역 모달 팝업 |

### 5. 은행 이체용 CSV 파일 규격 안내

다운로드되는 CSV 파일은 기업 뱅킹 대량 이체 업로드 및 회계 전표 연동에 최적화되어 있습니다.

| 열 순번 | 항목명 | 설명 및 포맷 |
|:---:|:---|:---|
| 1 | 순번 | 1부터 시작하는 일련번호 |
| 2 | 입금은행 | 예: 국민은행, 신한은행 |
| 3 | 입금계좌번호 | 하이픈 포함 계좌번호 (지수 변환 방지 탭 문자 포함) |
| 4 | 예금주 | 수취인 예금주명 |
| 5 | 실지급액(세후) | 순수 이체 대상 금액 (숫자) |
| 6 | 세전총액 | 원천세 공제 전 총액 |
| 7 | 원천세(3.3%) | 공제 세액 합계 |
| 8 | 성명 | 영업 인력 성명 |
| 9 | 소속팀 | 영업 본부/팀명 |
| 10 | 직책 | 상담사, 팀장, 본부장 등 |
| 11 | 지급상태 | 지급완료, 지급승인 등 |
| 12 | 지급일자 | YYYY-MM-DD 포맷 |
| 13 | 정산회차 | 회차 명칭 |
| 14 | 비고/메모 | 특이사항 |
