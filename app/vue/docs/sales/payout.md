> **수수료 지급 관리** 페이지는 확정된 정산 내역을 바탕으로 금융 이체 승인, 기업 인터넷 뱅킹 대량 이체 파일(CSV) 다운로드, 그리고 지급 완료 및 보류 처리를 일괄/개별 관리하는 자금 집행 센터입니다.

* **접근 경로**: 시스템 좌측 내비게이션 메뉴에서 **[PJT 관리 시스템] → [분양 대행 관리] → [수수료 지급 관리]**를 선택하여 접속합니다.

```mermaid
flowchart LR
    A["1. 확정 회차 조회<br>(정산 완료 내역 로드)"] --> B["2. 대량 이체 CSV 다운로드<br>(기업 뱅킹 표준 서식)"]
    B --> C["3. 인터넷 뱅킹 이체 실행<br>(은행 대량 이체 업로드)"]
    C --> D["4. 선택 지급완료 일괄 처리<br>(이체 완료일 자동 각인)"]
    D --> E["🏛️ 익월 10일 원천세 신고<br>(3.3% 예수금 세무 납부)"]
```

## 1. 개요 및 주요 기능

정산이 최종 확정된 수수료에 대해 실제 금융 이체와 자금 집행을 총괄하는 화면입니다.
* **지급 진척도 실시간 모니터링**: 전체 실지급 대상액과 현재까지의 이체 완료액, 진행률(%)을 실시간으로 추적합니다.
* **원천세 예수금(3.3%) 사전 파악**: 익월 10일 세무서 및 구청에 신고·납부해야 할 소득세(3%) 및 지방소득세(0.3%) 예수금 합계를 사전에 파악하여 세무 리스크를 방지합니다.
* **기업 인터넷 뱅킹 대량 이체용 CSV 다운로드**:
  * 엑셀에서 바로 열어도 한글이 깨지지 않도록 표준 인코딩(UTF-8 BOM)을 적용했습니다.
  * 계좌번호 앞자리 '0' 유실 및 지수 표기(예: `1.23E+11`) 방지 서식을 적용하여 안전한 이체를 지원합니다.
* **다중 선택 기반 일괄 상태 변경**: 체크박스로 여러 명을 선택하여 `[선택 승인]`, `[선택 지급완료]`, `[선택 지급보류]`를 원클릭으로 처리할 수 있습니다.

## 2. 화면 구성 및 조작 가이드

### 1. 회차 선택 및 필터 툴바
* **정산 회차 선택**: 지급을 진행할 정산 회차 선택
* **지급 상태 필터**: `전체`, `지급대기`, `지급승인`, `지급완료`, `지급보류`
* **통합 검색창**: 성명, 소속 팀, 예금주, 계좌번호로 실시간 검색
* **조회 건수 표출**: 필터 조건에 부합하는 대상 인원수 표시

### 2. 지급 진행 현황 대시보드 (상단 요약 카드)
* **총 실지급 대상액 (세후)**: 이번 회차에 집행되어야 할 총 이체 대상 금액
* **지급 완료액 (이체완료)**: 이미 지급 완료 처리된 금액과 전체 대비 진척률(%)
* **지급 잔액 (대기/보류)**: 아직 이체되지 않고 남아있는 잔액과 대기 인원수
* **원천세 예수금 합계 (3.3%)**: 회사가 원천징수하여 다음 달 10일에 국세청(소득세 3%) 및 지자체(지방소득세 0.3%)에 납부해야 할 세액 총액

### 3. 일괄 작업 및 이체 파일 다운로드 액션 바
* **전체 선택 체크박스**: 현재 필터링된 모든 항목을 일괄 선택하거나 해제
* **선택 정보 배지**: 현재 선택된 인원수와 세후 실지급 합계 금액을 실시간 계산하여 표출
* **일괄 상태 변경 버튼군**:
  * **`[선택 승인]`**: 선택된 인력들의 상태를 `지급승인`으로 일괄 변경
  * **`[선택 지급완료]`**: 이체가 완료된 후 선택된 인력들의 상태를 `지급완료`로 변경 (오늘 날짜가 지급일로 자동 각인)
  * **`[선택 지급보류]`**: 계좌 오류나 서류 미제출 등으로 이체를 보류할 때 지정
  * **`[선택 해제]`**: 선택 상태 초기화
* **[은행 이체용 CSV 다운로드] 버튼**: 기업 뱅킹 대량 이체 표준 규격에 맞춘 CSV 파일 다운로드

### 4. 지급 명세 테이블

| 항목 | 상세 설명 및 실무 기준 |
|:---|:---|
| **선택 체크박스** | 일괄 상태 변경 또는 선별 이체 다운로드를 위한 체크박스 |
| **소속 팀 / 직책 / 성명** | 영업 인력의 인적 정보 |
| **은행명 / 계좌번호 / 예금주** | 수수료가 입금될 금융 계좌 정보 |
| **총액 (세전)** | 정산된 세전 총액 |
| **원천세 (3.3%)** | 공제되는 원천징수 세액 |
| **실지급액 (세후)** | 통장에 실제 입금될 금액 (굵은 글씨 강조) |
| **지급 상태** | 드롭다운 셀렉터로 즉시 상태 변경 가능 (`지급대기`, `지급승인`, `지급완료`, `지급보류`) |
| **상세** | `[내역]` 버튼 클릭 시 개인별 상세 계약 내역 팝업 호출 |

### 5. 은행 대량 이체용 CSV 규격 안내

다운로드되는 CSV 파일은 기업 뱅킹 사이트의 '대량 이체 / 급여 이체' 업로드 양식에 부합하도록 구성되어 있습니다:

| 열 순번 | 항목명 | 상세 설명 및 포맷 |
|:---:|:---|:---|
| 1 | 순번 | 1부터 시작하는 일련번호 |
| 2 | 입금은행 | 예: 국민은행, 신한은행, 우리은행, 하나은행 등 |
| 3 | 입금계좌번호 | 하이픈 포함 계좌번호 (지수 변환 방지 텍스트 서식 적용) |
| 4 | 예금주 | 수취인 예금주명 |
| 5 | 실지급액 (세후) | 순수 이체 대상 금액 (숫자) |
| 6 | 세전총액 | 원천세 공제 전 총액 |
| 7 | 원천세 (3.3%) | 공제 세액 합계 |
| 8 | 성명 | 영업 인력 성명 |
| 9 | 소속팀 | 영업 본부 및 팀명 |
| 10 | 직책 | 상담사, 팀장, 본부장 등 |
| 11 | 지급상태 | 지급완료, 지급승인 등 |
| 12 | 지급일자 | YYYY-MM-DD 포맷 |
| 13 | 정산회차 | 회차 명칭 |
| 14 | 비고/메모 | 특이사항 |

## 3. 신입사원을 위한 실무 가이드

* **💡 금융 이체 실무 3단계 요령**:
  1. `[수수료 지급 관리]` 화면에서 회차를 선택하고, 계좌 오류자가 없는지 검토한 후 **[은행 이체용 CSV 다운로드]**를 클릭합니다.
  2. 회사 거래 은행의 기업 인터넷 뱅킹에 로그인하여 `[대량/급여 이체]` 메뉴에 해당 CSV 파일을 업로드하고 비밀번호 및 OTP를 인증하여 이체를 실행합니다.
  3. 이체가 정상 완료되면 시스템으로 돌아와 전체 선택 후 **`[선택 지급완료]`** 버튼을 눌러 상태를 업데이트합니다.
* **💡 세무 신고 연계 팁 (원천세 3.3%)**:
  * 화면 상단 요약 카드의 **'원천세 예수금 합계(3.3%)'**는 이번 달에 상담사들에게 지급하면서 원천징수한 세금 총액입니다. 회계팀 또는 세무대리인에게 전달하여 **익월 10일까지 홈택스(국세 3%) 및 위택스(지방세 0.3%)에 원천세 신고 및 납부**를 완료하도록 안내하십시오.
