# 수수료 정책 관리

프로젝트의 차수(OrderGroup) 및 유니트 타입(UnitType)별로 적용할 영업 직책별 수수료(상담사, 팀장, 본부장 R값)와 MGM 소개 수수료를 사전에 매트릭스로 책정하는 기준 정책 관리 페이지입니다.

- **위치**: `PJT 관리 시스템 > 분양 대행 관리 > 수수료 정책 관리`

## 개요

분양 성공 시 영업 인력에게 지급할 성과급(인센티브 R값)의 기준표를 사전에 정의합니다. 주거용, 상업용 등 유니트 타입이나 차수에 따라 건당 수수료 금액이 상이하므로, 이를 매트릭스 형태로 등록하여 계약 체결 시 정확한 수수료가 자동으로 계산되도록 지원합니다. 상담사 개인 수수료뿐만 아니라 관리 조직인 팀장 및 본부장의 오버라이딩 수수료, 외부 공인중개사 유치 시 지급할 MGM 소개료까지 하나의 정책으로 통합 관리합니다.

## 주요 기능

- **차수 및 타입별 수수료 매트릭스**: 프로젝트 차수와 유니트 타입별 개별 정책 등록
- **직책별 차등 수수료(R값) 설정**:
  - 담당 상담사 건당 수수료 (`agent_fee`)
  - 팀장 건당 수수료 (`leader_fee`)
  - 본부장 건당 수수료 (`director_fee`)
- **MGM 연계 수수료 설정**: 공인중개사 소개 시 지급할 MGM 수당 (`mgm_fee`)
- **수수료 지급 조건 설정**: 계약금 완납 시 100%, 1/2차 분할 지급, 공급계약 체결 시 등 지급 조건 명시
- **적용 유효 기간 및 활성 상태 관리**: 시작일/종료일 지정 및 정책 활성화 토글
- **통계 요약 카드 제공**: 등록된 정책 수, 평균 상담사 수수료, 최고 수수료, 최저 수수료 한눈에 파악

## 화면 구성

### 1. 상단 수수료 정책 요약 카드

- **총 등록 정책 수**: 현재 프로젝트에 등록된 수수료 정책 건수
- **평균 상담사 수수료**: 등록된 정책들의 상담사 평균 건당 수수료 금액
- **최고 수수료**: 가장 높은 금액으로 책정된 유니트 타입의 수수료
- **최저 수수료**: 가장 낮은 금액으로 책정된 유니트 타입의 수수료

### 2. 수수료 정책 목록 및 필터 바

- **차수 필터**: 특정 분양 차수별 필터링
- **타입 필터**: 특정 유니트 타입별 필터링
- **검색창**: 정책명 키워드 검색
- **[신규 정책 등록] 버튼**: 새로운 수수료 기준표를 등록하는 모달 호출 (`primary`)

### 3. 수수료 정책 대장 테이블

| 항목 | 설명 |
|:---|:---|
| **정책명** | 정책 명칭 (예: "1차 84A타입 기본 수수료") |
| **적용 차수 / 타입** | 해당 정책이 적용되는 차수 그룹 및 유니트 타입 |
| **상담사 수수료** | 계약 성사 상담사에게 지급되는 건당 인센티브 금액 |
| **팀장 수수료** | 해당 팀의 팀장에게 귀속되는 오버라이딩 수수료 |
| **본부장 수수료** | 상위 본부장에게 귀속되는 오버라이딩 수수료 |
| **MGM 소개료** | 외부 공인중개사 소개 성약 시 지급되는 건당 수수료 |
| **지급 조건** | 계약금 100% 완납, 분할 지급 등 설정된 지급 조건 |
| **적용 기간** | 정책의 효력이 유지되는 유효 기간 (시작일 ~ 종료일) |
| **상태** | 활성(초록 뱃지) 또는 비활성(회색 뱃지) |
| **관리** | 행별 수정(`[연필]`, `success`) 및 삭제(`[휴지통]`, `danger`) 버튼 |

### 4. 수수료 정책 등록/수정 모달 (PolicyFormModal)

| 입력 항목 | 필수 여부 | 설명 및 비고 |
|:---|:---:|:---|
| **정책명** | 필수 | 식별하기 쉬운 수수료 정책 이름 |
| **적용 차수** | 선택 | 특정 차수에 한정할 경우 선택 (미선택 시 전체 차수) |
| **적용 유니트 타입** | 선택 | 특정 평형/타입에 한정할 경우 선택 |
| **상담사 수수료 (원)** | 필수 | 담당 상담사 건당 지급액 |
| **팀장 수수료 (원)** | 선택 | 팀장 오버라이딩 수당 |
| **본부장 수수료 (원)** | 선택 | 본부장 오버라이딩 수당 |
| **MGM 소개 수수료 (원)** | 선택 | 공인중개사 연계 시 건당 소개료 |
| **지급 조건** | 필수 | 1. 완납 시 전액, 2. 분할 지급, 3. 공급계약 체결 시, 4. 청약 시 |
| **적용 시작일** | 필수 | 정책 효력 시작 일자 (`DatePicker`) |
| **적용 종료일** | 선택 | 정책 종료 일자 (`DatePicker`, 무기한 시 공란) |
| **활성화 여부** | 필수 | 체크박스를 통해 현재 적용 여부 설정 |
