# 분양 조건 설정

::: tip 📸 실제 화면 안내
![분양 조건 및 납부 회차 설정 화면](./images/settings.png)
*관리자 참고: 해당 화면의 실제 캡처 이미지를 `./images/settings.png` 경로에 등록해 주세요.*
:::

> **분양 조건 설정**은 프로젝트의 납부 회차별 납부 일정, 계약금 및 세부 공급 가격, 구비 서류, 유상 옵션 등 분양 계약 체결과 수납 관리에 직접적으로 적용되는 핵심 계약 조건을 총괄 설정하는 모듈입니다.

* **접근 경로**: 시스템 좌측 내비게이션 메뉴에서 **[PJT 관리 시스템] → [프로젝트 설정] → [분양 조건 설정]**을 선택하여 접속합니다.

## 1. 납부 회차 등록

계약금, 중도금, 잔금 등 분양 대금의 납부 회차를 정의하고, 각 회차별 납부 기한 및 선납할인/연체가산 기준을 설정합니다.

* **위치**: `프로젝트 설정 > 분양 조건 설정 > 납부 회차 등록`

| 라벨 | 필수입력 | 상세 설명 및 실무 기준 |
|:---|:---:|:---|
| **타입 종류** | **필수** | 공동주택, 오피스텔 등 시설 용도별 회차 구분 |
| **회차 종류** | **필수** | 계약금, 중도금, 잔금, 업무대행비 등 회차 성격 선택 |
| **계약금 산정방법** | | (계약금인 경우) 등록 계약 금액 우선 또는 분양가 대비 비율 중 선택 |
| **납입회차 코드** | **필수** | **납부 시점(타이밍)** 그룹화 코드. 동일 기한 내 납부 항목은 같은 코드 부여 |
| **납부순서** | **필수** | **수납 정산 우선순위**. 입금 발생 시 장부상 먼저 채워지는 절대적 순서 |
| **회차 명 / 별칭** | **필수** | 납부 고지서 등에 공식 표출될 회차 명칭 (예: `1차 계약금`, `중도금 1회차`) |
| **납부 약정금액** | | 정액으로 정해진 경우 입력 (예: 업무대행비 1,000만 원) |
| **납부비율(%)** | | 분양가 대비 납부 비율 (잔금은 100%에서 자동 계산) |
| **납부 약정일** | | 확정된 고정 납부 기한이 있는 경우 날짜 지정 |
| **전회 기준 경과일수** | | 전 회차(예: 계약일)로부터 일정 기간 후 납부 시 설정 (예: 30일 이내) |
| **선납/연체 설정** | | 선납할인율, 연체가산율 및 각각의 적용 기준일 설정 |

### 💡 납입회차 코드 vs 납부순서, 쉽게 이해하기

두 항목을 명확히 구분하는 이유는 **"동시에 내는 돈이라도 장부상 정산 순서가 다르기 때문"**입니다.

* **납입회차 코드 (시점 - When)**: "언제 내는가?" 즉, 고지서에 한 묶음으로 청구되는 **납부 시점 그룹**입니다.
* **납부순서 (우선순위 - Priority)**: "무엇을 먼저 채우는가?" 즉, 대금이 일부만 입금되었을 때의 **장부 정산 순위**입니다.

**[실무 사례: 2회차 납부 기한에 계약금과 업무대행비를 각각 1,000만 원씩 받는 경우]**

| 항목 명칭 | **회차 코드 (시점)** | **납부 순서 (우선순위)** | 시스템 정산 로직 |
|:---|:---:|:---:|:---|
| **2차 계약금** | **2** | **2** | 입금 발생 시 가장 먼저 채워짐 |
| **업무대행비** | **2** | **3** | 계약금이 다 채워진 후 남은 금액이 채워짐 |

* **실제 작동**: 만약 계약자가 2,000만 원 중 **1,500만 원만 입금**했다면, 시스템은 **납부순서**에 따라 `[2차 계약금]` 1,000만 원을 완납 처리하고, 남은 500만 원을 `[업무대행비]`의 일부 납부로 자동 배정합니다.

## 2. 계약 금액 등록

차수 및 타입별로 고정된 계약 금액을 설정합니다.

* **등록 대상**: 동호 미지정 계약이나 타입별(층별 구분 없이) 일괄 정액제 계약금을 운영할 때 등록합니다.
* **위치**: `프로젝트 설정 > 분양 조건 설정 > 계약 금액 등록`

| 라벨 | 필수입력 | 상세 설명 및 실무 기준 |
|:---|:---:|:---|
| **차수** | **필수** | 대상 계약 차수 그룹 선택 |
| **타입** | **필수** | 대상 유닛 타입 선택 |
| **회차별 납부금액** | **필수** | 해당 차수/타입에 적용할 정액 계약금액 |

## 3. 공급 가격 등록

동/타입/층별 범위에 따른 실제 공급 가격을 등록합니다. 건물가, 대지가, 부가세를 구분하여 관리합니다.

* **위치**: `프로젝트 설정 > 분양 조건 설정 > 공급 가격 등록`

| 라벨 | 필수입력 | 상세 설명 및 실무 기준 |
|:---|:---:|:---|
| **구분 / 차수 / 타입** | **필수** | 가격을 등록할 상세 범위 선택 |
| **층별 조건** | **필수** | 등록된 층 범위(저층부, 기준층 등) 선택 |
| **건물가 / 대지가** | **필수** | 각 항목별 금액 입력 (단위: 원) |
| **부가세** | **필수** | 건물분에 대한 부가세(10%) 입력 |
| **기준공급가** | **필수** | 건물가 + 대지가 + 부가세 합계 (시스템 자동 계산) |
| **특별약정 추가** | | 특정 회차에 대해 비율이 아닌 확정 금액을 적용할 경우 설정 |

### 전체 계약건 공급가 재설정 (관리자 전용 기능)
공급 가격이나 계약 금액 정보를 사후 수정한 후, 이미 등록된 모든 계약 데이터에 변경된 내용을 일괄 반영할 때 사용합니다.
* **미리보기**: 실제 반영 전 업데이트 대상 계약 건수와 샘플 데이터를 화면의 팝업창을 통해 사전 검토합니다.
* **전체 공급가 재설정**: 현재 등록된 최신 공급 가격 및 계약 금액 데이터를 기반으로 모든 계약 건의 가격 정보를 강제로 재설정합니다.
* **⚠️ 주의사항**: 이 작업은 복구가 불가능하며 등록된 모든 계약 데이터의 수납 약정 금액이 변경될 수 있으므로 사전에 전산 담당자와 상의 후 매우 신중하게 실행해야 합니다.

## 4. 구비 서류 등록

계약 체결 시 계약자가 제출해야 하는 필수 증빙 서류 및 동의서 목록을 관리합니다.

* **위치**: `프로젝트 설정 > 분양 조건 설정 > 구비 서류 등록`

| 라벨 | 필수입력 | 상세 설명 및 실무 기준 |
|:---|:---:|:---|
| **서류구분** | **필수** | 증빙서류(인감증명 등) 또는 동의서류(약정서, 개인정보동의 등) 중 선택 |
| **서류 유형** | **필수** | 주민등록등본, 인감증명서, 신분증 사본 등 세부 유형 선택 |
| **필요 수량** | | 제출받아야 할 서류 부수 |
| **필수 여부** | **필수** | `필수`, `선택`, `조건부 필수` 중 선택 |
| **설명 / 표시 순서** | | 서류 지참 안내 시 참고사항 및 목록 노출 순서 |

## 5. 옵션 품목 등록

발코니 확장, 시스템 에어컨, 빌트인 가전 등 수분양자가 선택할 수 있는 유상 옵션 품목을 관리합니다.

* **위치**: `프로젝트 설정 > 분양 조건 설정 > 옵션 품목 등록`

| 라벨 | 필수입력 | 상세 설명 및 실무 기준 |
|:---|:---:|:---|
| **타입구분** | **필수** | 해당 옵션을 선택할 수 있는 대상 타입 (다중 선택 가능) |
| **품목 코드 / 이름** | **필수** | 옵션 품목 식별 정보 (예: `발코니확장`, `시스템에어컨4대`) |
| **세대 옵션** | | 규격, 색상 등 세부 선택 사항 |
| **제조사** | | 품목의 제조사 또는 브랜드 |
| **옵션 가격** | **필수** | 총 판매 가격 |
| **계약금 / 잔금** | | 옵션 대금 분납 시 각 금액 설정 |

## 6. 💡 분양가 및 납부 금액 산출 우선순위 요약

IBS 시스템은 복잡한 분양 전략을 완벽히 소화하기 위해 다단계 우선순위 로직을 사용합니다.

### 1. 공급 가격 산출 우선순위
시스템은 계약서 생성 시 **[개별 계약 가격 > 기준 공급 가격 > 예산 단가 > 타입 단가]** 순으로 유효한 값을 찾아 적용합니다. 따라서 상세한 공급 가격표를 등록하기 전이라도 예산이나 타입 정보만 있다면 대략적인 분양가 산출이 가능합니다.

### 2. 회차별 납부 금액 산출 우선순위

| 순위 | 항목 명칭 | 설정 메뉴 | 적용 범위 (Scope) | 실무 활용 예시 |
|:---:|:---|:---|:---|:---|
| **1순위** | **회차별 고정 금액** | [납부 회차 등록] | **프로젝트 전체** | 모든 세대의 업무대행비를 1,000만 원으로 고정할 때 |
| **2순위** | **특별 약정 금액** | [공급 가격 등록] | **특정 가격 조건** | 펜트하우스만 계약금을 5,000만 원 정액으로 받을 때 |
| **3순위** | **타입별 계약 금액** | [계약 금액 등록] | **특정 타입별** | 84타입 전체에 동일한 3,000만 원 정액 계약금을 걸 때 |
| **4순위** | **납부 비율 계산** | [납부 회차 등록] | **프로젝트 전체** | (기본값) 공급가에 비율(10%, 60% 등)을 곱해 산출 |

* **잔금 자동 보정**: 잔금은 `[총 공급가 - (계약금 + 중도금 + 기타 회차 합계)]`로 시스템이 자동 계산하여 단수 차액을 완벽하게 맞춥니다.
