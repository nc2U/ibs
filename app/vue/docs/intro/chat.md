# 사내 메신저 (실시간 채팅)

IBS 사내 메신저는 웹과 모바일 앱 어디서나 전사 임직원 및 프로젝트 구성원들과 실시간으로 소통할 수 있는 협업 도구입니다. 프로젝트별 자동 생성되는 공용 채널, 1:1 대화, 개인 메모 공간을 지원하며, 업무 중
발생한 문서와 미디어를 영구 보관하여 신속하게 찾아볼 수 있습니다.

## 진입 방법

### 데스크톱 웹 (PC)

* 상단 내비게이션 바 우측의 **메신저 아이콘**(<span class="mdi mdi-chat-processing-outline"></span>)을 클릭합니다.
* 화면 우측에서 슬라이드 드로어 (Drawer) 형태로 열리며, 현재 작업 중인 페이지의 흐름을 방해하지 않고 소통할 수 있습니다.
* 상단 헤더 우측의 **닫기 버튼**(<span class="mdi mdi-close"></span>)을 누르면 드로어가 닫힙니다.

### 모바일 앱 (iOS / Android)

* 앱 화면 최상단 글로벌 헤더 (앱바) 우측의 **메신저 아이콘**(<span class="mdi mdi-message-text-outline"></span>)을 탭합니다.
* 전체 화면 채팅 목록 및 대화방으로 진입하며, 실시간 푸시 알림 수신 시 알림을 직접 탭하여 해당 대화방으로 바로 이동할 수도 있습니다.

## 대화방 유형

IBS 사내 메신저는 목적에 따라 3가지 대화방을 제공합니다.

| 대화방 구분     |                    아이콘                    | 설명                                                       | 참여 대상                    |
|:----------------|:--------------------------------------------:|:-----------------------------------------------------------|:-----------------------------|
| **공용 채널**   |     <span class="mdi mdi-pound"></span>      | 프로젝트(워크스페이스) 단위로 자동 개설되는 전체 소통 공간 | 해당 프로젝트 참여 멤버 전원 |
| **1:1 대화**    |    <span class="mdi mdi-account"></span>     | 임직원 간의 개별 비공개 업무 대화                          | 초대한 상대방 및 본인 (2인)  |
| **나와의 채팅** | <span class="mdi mdi-bookmark-check"></span> | 개인 업무 메모, 링크, 임시 파일 보관을 위한 전용 공간      | 본인 전용 (외부 노출 없음)   |

### 1. 공용 채널 (#프로젝트명)

* 프로젝트 (워크스페이스)가 등록되면 해당 프로젝트의 기본 소통 채널이 자동으로 연동됩니다.
* 프로젝트에 소속된 모든 멤버가 자유롭게 의견을 나누고 공지사항을 공유할 수 있습니다.

### 2. 새 1:1 대화 시작 및 나가기

* **새 대화 시작**: 대화방 목록 상단의 **새 1:1 대화 버튼**(<span class="mdi mdi-account-plus-outline"></span>)을 클릭한 후, 사용자 목록에서 대화할 동료를
  선택합니다.
* **대화방 나가기**: 1:1 대화방 헤더 우측의 **나가기 버튼**(<span class="mdi mdi-exit-to-app"></span>)을 누르면 내 대화방 목록에서 숨김 처리됩니다. 상대방이 새
  메시지를 보내면 목록에 다시 표시됩니다.

### 3. 나와의 채팅

* 대화방 목록 상단에 항상 고정 표출됩니다.
* 업무 중 기억해야 할 메모, 확인해야 할 링크, 임시 파일이나 이미지를 나만의 공간에 안전하게 스크랩해 둘 수 있습니다.

## 주요 메시지 기능

### 1. 실시간 메시지 전송 및 읽음 확인

* **실시간 동기화**: 상대방이 작성한 메시지가 별도의 새로고침 없이 화면에 즉시 표시됩니다.
* **상대방 입력 표시**: 대화 상대가 메시지를 입력 중일 때 입력창 상단에 실시간으로 입력 중 표시가 나타납니다.
* **안 읽은 멤버 수**: 전송된 메시지 옆에 아직 확인하지 않은 참여자 수가 숫자로 표시됩니다.

### 2. 특정 메시지 답장 (Reply)

* 메시지에 마우스를 올리거나 탭한 뒤 **답장 아이콘**을 클릭하면 해당 메시지가 입력창 상단에 인용 카드로 표시됩니다.
* 인용 카드가 연결된 상태에서 텍스트나 파일을 전송하면, 원본 메시지와 맥락이 연결되어 무엇에 대한 답변인지 명확하게 확인할 수 있습니다.

### 3. 파일 및 사진 첨부

* 입력창 좌측의 **클립 아이콘**(<span class="mdi mdi-paperclip"></span>)을 눌러 문서 (PDF, Excel, Word 등)나 현장 사진/동영상을 첨부할 수 있습니다.
* 전송된 이미지는 채팅방 내에서 썸네일 미리보기를 제공하며, 클릭 시 원본 크기로 확인하거나 다운로드할 수 있습니다.

### 4. 메시지 삭제

* 본인이 작성한 메시지의 메뉴에서 **삭제**를 선택하면 대화방에서 즉시 제거됩니다.

## 검색 및 보관함 활용

### 1. 대화방 내 검색

* 대화방 상단 헤더의 **검색 아이콘**(<span class="mdi mdi-magnify"></span>)을 클릭하면 검색창이 나타납니다.
* 찾고자 하는 키워드를 입력하면 서버 전체 메시지 데이터베이스에서 일치하는 메시지를 실시간으로 검색합니다.
* **위/아래 방향키 버튼**을 눌러 이전/다음 검색 결과로 빠르게 이동할 수 있으며, 해당 시점의 전후 대화 맥락을 함께 조회할 수 있습니다.

### 2. 통합 전역 검색

* 대화방 목록 화면에서 상단의 **검색 버튼**을 누르면 내가 속한 모든 대화방을 대상으로 통합 키워드 검색을 수행할 수 있습니다.

### 3. 파일/미디어 보관함 서랍

* 대화방 상단 헤더의 **폴더 아이콘**(<span class="mdi mdi-folder-open-outline"></span>)을 클릭하면 우측에 전용 파일 보관함 서랍이 열립니다.
* 대화방에서 공유된 모든 파일과 사진만을 일목요연하게 모아서 열람하고 다운로드할 수 있어, 지난 첨부파일을 찾기 위해 과거 대화를 일일이 스크롤할 필요가 없습니다.

## 알림 및 연결 편의 기능

### 최신 대화로 복귀 버튼

* 과거 대화를 검색하거나 스크롤하여 위쪽을 열람하고 있을 때 새 메시지가 수신되어도 화면이 멋대로 맨 아래로 튀지 않도록 보호됩니다.
* 하단에 나타나는 **최신 대화로 이동 버튼**(<span class="mdi mdi-chevron-down"></span>)을 클릭하면 언제든지 즉시 가장 최근 대화 위치로 복귀합니다.

### 모바일 백그라운드 푸시 알림

* 모바일 앱이 백그라운드에 있거나 화면이 꺼져 있어도 새로운 메시지가 도착하면 헤드업 푸시 알림이 발송됩니다.
* 알림을 탭하면 즉시 해당 대화방으로 바로 이동합니다.
