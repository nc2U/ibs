# 일반 문서 관리

프로젝트와 관련된 각종 공문, 사업 협약서, 지침, 인허가 서류 등 일반적인 업무 자료들을 카테고리별로 안전하게 보관하고 구성원들과 공유하는 화면입니다.

- **위치**: `문서 소송 관리 > 일반 문서 관리`

## 개요

부동산 개발 프로젝트 진행 과정에서 발생하는 다양한 형식의 문서(보고서, 도면, 공문, 계약서 사본)와 외부 참조 웹 링크를 체계적으로 자산화합니다. 탭 형태의 직관적인 카테고리 분류를 통해 필요한 자료를 신속하게 검색할 수 있으며, 다중 첨부 파일과 파일별 용도 설명, 외부 웹 링크 등록, 그리고 개인별 중요 문서 스크랩 기능을 제공합니다.

```mermaid
flowchart LR
    A["1. 카테고리 탭 선택<br/>(공문·협약·인허가·보고서)"] --> B["2. 문서 검색 및 정렬<br/>(제목·내용·작성자 필터)"]
    B --> C["3. 상세 열람 및 자원 활용<br/>(본문·첨부파일·참조링크)"]
    C --> D["4. 중요 문서 스크랩<br/>(개인 보관함 즐겨찾기)"]
    D --> E["5. 신규 문서 작성·수정<br/>(다중 파일 및 설명 첨부)"]
```

## 주요 기능

- **카테고리 탭 분류 체계**: 인허가, 사업 협약, 설계/감리, 일반 공문 등 프로젝트 성격에 맞게 정의된 카테고리별 원클릭 탭 필터링
- **다중 파일 첨부 및 파일별 설명**: 여러 개의 첨부 파일을 동시에 업로드할 수 있으며, 원본 파일명을 바꾸지 않고도 '최종 승인 날인본', '검토용 도면' 등 세부 설명을 기재 가능
- **외부 참조 웹 링크 연동**: 지자체 고시 공고, 법령 정보, 전자공시시스템(DART) 등 온라인 외부 웹사이트 URL을 문서 자원으로 직접 등록
- **개인 맞춤형 문서 스크랩**: 자주 찾아보거나 중요한 문서를 '내 스크랩' 보관함에 담아 마이페이지 등에서 언제든 빠르게 재접근
- **정밀한 3단 조회수(Hit) 추적**: 문서 자체의 조회수뿐만 아니라, 첨부된 파일 다운로드 횟수와 외부 링크 클릭 횟수를 개별 집계하여 구성원들의 자료 활용도 파악
- **권한 기반 열람 및 작성 제어**: 프로젝트 참여 구성원 권한에 따른 안전한 문서 등록, 수정 및 삭제 통제

## 화면 구성 및 실무 가이드

### 1. 목록 제어 및 검색 영역

필요한 문서를 신속하게 찾기 위한 조건 필터와 카테고리 탭을 제공합니다.

- **카테고리 탭**: 상단에 배치된 분류 탭(예: 전체, 인허가, 계약/협약, 공문 등)을 클릭하여 해당 분류의 문서만 즉시 선별합니다.
- **검색 및 정렬 옵션**:
  - `검색창`: 제목, 본문 내용, 작성자 이름으로 키워드 통합 검색
  - `정렬 기준`: 등록일시 최신순(기본), 조회수 높은순 등으로 정렬 순서 전환
  - `페이지당 표시 건수`: 10건, 20건, 30건, 50건 단위 선택

### 2. 문서 목록 테이블

조회된 문서의 기본 요약 정보와 첨부 자원 유무를 한눈에 확인할 수 있습니다.

- **표시 항목**: 카테고리 태그, 문서 제목, 첨부 자원 아이콘(파일 아이콘 📎, 링크 아이콘 🔗), 작성자, 등록일시, 조회수
- **첨부 자원 직관적 식별**: 제목 옆에 첨부 파일 개수와 외부 링크 개수가 아이콘과 함께 표시되어, 본문에 들어가지 않고도 첨부물 유무를 즉시 알 수 있습니다.

### 3. 문서 상세 보기 (View)

선택한 문서의 상세 내용과 첨부된 모든 자료를 열람하는 화면입니다.

- **본문 영역**: 서식이 적용된 텍스트와 등록된 이미지, 설명문 확인
- **첨부 파일 목록**: 등록된 파일명, 파일 용량, **파일별 세부 설명**이 함께 표시되며, 클릭 시 즉시 다운로드됩니다. (다운로드 시 파일별 다운로드 횟수 자동 카운트)
- **참조 링크 목록**: 연계된 외부 사이트 링크가 표시되며, 클릭 시 새 창으로 연결됩니다. (클릭 시 링크별 조회수 자동 카운트)
- **스크랩 버튼**: 문서 우측 상단의 [스크랩] 아이콘을 누르면 내 개인 스크랩 목록에 즉시 추가되어 즐겨찾기처럼 활용할 수 있습니다.

### 4. 문서 작성 및 수정 (Form)

새로운 문서를 프로젝트 자료실에 등록하거나 기존 내용을 보완하는 폼입니다.

| 입력 항목 | 필수 여부 | 상세 설명 및 실무 팁 |
| :--- | :---: | :--- |
| **카테고리** | 필수 | 문서의 성격에 맞는 분류 항목(인허가, 계약, 공문 등)을 선택합니다. |
| **문서 제목** | 필수 | 다른 구성원이 문서 목록에서 쉽게 식별할 수 있도록 명확한 제목을 작성합니다. |
| **본문 내용** | 선택 | 문서의 개요, 주요 변경 사항, 취지 등을 서식 에디터로 작성합니다. |
| **첨부 파일** | 선택 | [파일 추가]를 눌러 여러 개의 문서를 첨부합니다. 각 파일마다 **'파일 설명'**란에 용도를 적어주면 협업 시 매우 유용합니다. |
| **참조 링크** | 선택 | [링크 추가]를 눌러 관련 웹사이트의 URL 주소와 링크 제목을 등록합니다. |

## 💡 실무 활용 팁

- **파일 설명 필드의 적극 활용**: 파일명이 난해한 스캔 파일(예: `Scan_20261027_001.pdf`)이라도 업로드 시 파일 설명에 **"건축허가 표지 및 조건부 승인 통보서"**와 같이 실무 명칭을 적어두면 동료들이 다운로드하지 않고도 파일 내용을 바로 파악할 수 있습니다.
- **외부 법령 및 지자체 고시 연동**: 인허가 조건이나 조례 개정안처럼 웹상에 공시된 자료는 파일로 저장해 두면 최신 내용과 달라질 수 있습니다. 이 경우 '참조 링크' 기능으로 지자체 고시 웹페이지를 직접 연결해 두면 항상 최신 공시 정보를 참조할 수 있습니다.
- **문서 수정 시 기존 파일 보존**: 문서 내용을 보완하거나 추가 파일을 등록할 때, 기존에 등록된 파일들은 삭제하지 않는 한 그대로 유지되므로 안심하고 수정 작업을 진행할 수 있습니다.
