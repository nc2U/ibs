# 사용자 관리 (User Management)

> **사용자 관리** 페이지는 시스템 관리자가 전사 구성원의 계정을 발급하고, 활성화 상태 및 권한 플래그 (`work_manager`)를 제어하며, 각 사용자의 업무 부하량·참여 워크스페이스·최근 활동 로그를
> 다각도로 모니터링하는 종합 계정 센터입니다.

## 1. 개요 및 계정 운영 흐름

관리자는 신규 입사자의 계정을 발급하고 필요한 워크스페이스에 즉시 역할을 배정할 수 있으며, 특정 사용자의 활동 추이를 대시보드 형태로 파악할 수 있습니다.

```mermaid
flowchart LR
    A["👤 계정 발급<br>(아이디·랜덤 암호·초대 메일)"] --> B["🏢 워크스페이스 Role 배정<br>(다중 역할 인라인 부여)"]
    B --> C["📊 활동 모니터링<br>(업무 통계·최근 실행 로그)"]
    C --> D["🔒 계정 생애주기 제어<br>(활성/비활성·비번 재설정)"]
```

## 2. 사용자 목록 그리드 및 필터

전체 사용자의 기본 정보와 시스템 접근 상태를 조회합니다.

* **계정 식별 정보**: 아이디, 이름, 이메일, 등록일시, 마지막 로그인 시각 (경과 시간 표출)
* **상태 배지**:
    * **활성 (`Active`)**: 정상 로그인 가능한 활성 계정
    * **잠금/비활성**: 로그인이 차단된 계정 (퇴사 또는 휴직 처리 시 활용)
* **권한 플래그**:
    * **업무 총괄 관리자 (`work_manager`)**: 모든 비공개 워크스페이스 및 설정을 제어할 수 있는 최고 권한
    * **관리자 (`is_staff`)**: 관리자 콘솔 접근 권한

## 3. 관리자 메뉴 (계정 편집 및 워크스페이스 배정)

사용자 편집 화면은 상단 탭을 통해 2개 영역으로 분리되어 제공됩니다.

### 📋 1. 일반 정보 탭 (`UserForm`)

* **기본 인적 사항**: 사용자 아이디, 공식 이메일 주소 등록
* **비밀번호 자동 생성기**: 복잡하고 안전한 임의 비밀번호를 원클릭으로 자동 생성하여 입력
* **초대/안내 메일 자동 발송**:
    * 새 계정 발급 시 로그인 링크와 초기 비밀번호 안내 메일을 해당 사용자의 이메일로 자동 전송 (초기 유효시간: 24시간)
* **계정 상태 및 플래그 제어**: 활성 여부 (`is_active`), 스태프 (`is_staff`), 업무관리자 (`work_manager`) 설정

### 🏢 2. 워크스페이스 탭

특정 사용자가 참여 중인 모든 워크스페이스를 한 화면에서 일괄 관리합니다.

* **다중 역할 (Role) 인라인 편집**: 각 워크스페이스별로 부여된 역할 (예: `업무관리자`, `개발자` 등)을 인라인 체크박스로 즉시 수정
* **새 워크스페이스 추가**: 모달 팝업을 통해 사용자를 새 워크스페이스에 참여시키고 권한 부여
* **워크스페이스 제외**: 더 이상 참여하지 않는 워크스페이스에서 해당 사용자를 즉시 멤버십 삭제

## 4. 사용자 상세 프로필 (User Detail View)

목록에서 특정 사용자를 클릭하면 해당 구성원의 모든 협업 데이터가 집약된 대시보드로 이동합니다.

### 📊 업무 통계 (Issue Summary)

* 사용자에게 할당된 전체 업무 수, **진행 중 (Open) 업무 건수**, **완료 (Closed) 업무 건수**를 카드로 시각화하여 현재 업무 부하량을 즉시 진단합니다.

### 🌲 참여 워크스페이스 트리 (Project Summary)

* 상위-하위 워크스페이스 계층 구조와 함께 사용자가 어떤 역할로 참여 중인지 트리 뷰로 조망합니다.

### ⏱️ 최근 활동 로그 피드 (Activity Log)

* 해당 사용자가 최근 생성하거나 수정한 업무, 작성한 댓글, 회의록, 문서 등 **최신 활동 내역 10건**을 타임라인 피드로 실시간 추적합니다. (클릭 시 [업무실행내역](/work-manage/activity)
  상세 페이지로 연동)

## 5. 실무 운영 가이드

* **퇴사 및 인사이동 처리**: 사용자가 퇴사할 경우 데이터를 임의 삭제하지 마시고, **`활성(is_active)` 체크를 해제**하여 기존 업무/결재 이력의 무결성을 보존하면서 로그인을 차단하십시오.
* **업무 부하 분산**: 업무 통계에서 특정 팀원의 진행 중 업무가 지나치게 많다면, 상세 화면에서 업무 목록을 검토하여 타 구성원에게 재배분하는 기준으로 활용하세요.
