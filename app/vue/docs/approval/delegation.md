# 결재 위임 (대결 관리)

결재권자가 휴가, 출장, 병가 등으로 자리를 비울 때 업무 지연을 방지하기 위해 대리 결재자(대결자)를 지정하여 결재 권한을 위임할 수 있습니다.

## 1. 결재 위임 설정 방법

1. 좌측 메뉴에서 **`전자 결재 관리` $\to$ `결재 위임 관리`**로 이동합니다.
2. `[위임 등록]` 버튼을 클릭합니다.
3. 아래 필수 항목을 입력 후 저장합니다:
   - **대결자 (위임 대상자)**: 본인을 대신하여 결재를 수행할 직원을 선택합니다.
   - **위임 기간**: 시작일자와 종료일자를 지정합니다. (기간 내에만 대결 권한이 활성화됩니다.)
   - **위임 사유**: 출장, 연차 휴가 등 사유를 입력합니다.

## 2. 대결 프로세스 및 시스템 동작

```
[기안 상신] ──▶ [원 결재자 부재] ──▶ [대결자에게 동시 알림] ──▶ [대결자 승인] ──▶ [대결 표기 및 다음 단계]
```

- **대결자 알림 수신**: 결재 요청이 발생하면 원 결재자뿐만 아니라 유효 기간 내의 **대결자에게도 결재 요청 알림이 발송**됩니다.
- **결재 대기함 노출**: 대결자의 `결재 대기함`에 대리 결재 대상 문서가 표시됩니다.
- **대결 승인 처리**:
  - 대결자가 문서를 열람하고 승인할 수 있습니다.
  - 결재 이력 및 타임라인에 **`대결: 홍길동 (원 결재자: 김팀장)`** 형태로 명확히 기록됩니다.
- **기간 만료 시 자동 해제**: 설정된 종료일자가 지나면 대결 권한은 자동으로 만료되어 안전하게 통제됩니다.

## 3. 유의 사항
- 대결자가 이미 승인 또는 반려한 결재 건은 원 결재자가 중복으로 처리할 수 없습니다.
- 관리자(`Superuser`)는 필요 시 특정 임직원의 부재를 대비하여 대리인을 사전에 직권으로 등록할 수 있습니다.
