# 결재 위임 및 대결 관리 (Delegation)

> **결재 위임(대결·代決)**은 결재권자가 출장, 연차 휴가, 병가 등으로 자리를 비울 때 결재선 병목과 업무 지연을 방지하기 위해, 지정된 기간 동안 특정 직원에게 결재 권한을 공식 위임하는 기능입니다.

* **접근 경로**: 시스템 좌측 내비게이션 메뉴에서 **[전자결재 시스템] → [결재 진행 및 처리] → [결재 위임 (대결 관리)]**를 선택하여 접속합니다.

## 1. 대결 프로세스 및 시스템 동작

```mermaid
flowchart TD
    A["기안 상신 (결재 대기 발생)"] --> B{"원 결재권자의 유효 대결자 존재 여부"}
    
    B -- " 대결 미설정 " --> C["원 결재자 대기함에만 표시"]
    
    B -- " 유효 대결자 존재 (진행중 상태) " --> D["원 결재자 & 대결자 동시 푸시 알림 발송"]
    D --> E["대결자의 [결재 대기함]에 자동 노출"]
    
    E --> F{"누가 먼저 처리하는가?"}
    F -- " 대결자가 승인 " --> G["✅ 승인 완료<br>이력 각인: '대결: 대결자명 (원 결재자: 위임자명)'"]
    F -- " 원 결재자가 직접 승인 " --> H["✅ 승인 완료<br>이력 각인: 원 결재자 단독 승인"]
    
    G & H --> I["다음 결재 단계로 진행"]
```

## 2. 결재 위임 설정 방법

1. 좌측 메뉴에서 **[전자결재 시스템] → [결재 진행 및 처리] → [결재 위임 (대결 관리)]**로 이동합니다.
2. 우측 상단의 **`[신규 대결자 지정]`** 버튼을 클릭합니다.
3. 팝업창에서 아래 4대 필수 항목을 입력하고 저장합니다:
   * **수임자 (대결자)**: 본인을 대신하여 결재 권한을 행사할 재직 직원을 검색하여 선택합니다.
   * **위임 시작일 / 종료일**: 대결 권한이 효력을 갖는 날짜 범위를 지정합니다.
   * **부재 및 위임 사유**: 출장, 해외 파견, 연차 휴가, 병가 등 구체적인 사유를 입력합니다.
   * **활성 여부**: 기본값은 활성 상태이며, 저장 즉시 해당 일자에 맞춰 적용됩니다.

## 3. 위임 목록 화면 및 3대 상태 구분

결재 위임 관리 화면에서는 **내가 위임한 내역(`본인 위임`)**과 **내가 위임받은 내역(`수임(대결)`)**을 통합 관리합니다.

| 상태 배지 | 상태 설명 | 대결 권한 효력 |
| :--- | :--- | :---: |
| **`진행중 (유효)`** | 오늘 날짜가 위임 기간 내에 포함되어 있고 활성 상태 | **실시간 대결 가능** |
| **`대기 / 예정`** | 위임 시작일이 아직 도래하지 않은 사전 예약 상태 | 효력 대기 |
| **`비활성 (해제)`** | 기간이 만료되었거나 토글로 일시정지된 상태 | 권한 차단 |

* **원터치 조기 복귀 해제**: 출장에서 예정보다 일찍 복귀한 경우, 등록된 내역을 삭제할 필요 없이 목록의 **`[해제]`** 버튼을 누르면 대결 권한이 즉시 중단됩니다.
* **수정 및 삭제**: 위임 기간이나 대결자를 변경해야 할 경우 언제든지 팝업에서 수정하거나 삭제할 수 있습니다.

## 4. 보안 및 감사 추적 (Audit Trail)

* **결재 이력 투명성**: 대결자가 결재(승인 또는 반려)를 수행하면, 전자결재 타임라인 및 생성되는 인쇄용 PDF 결재란에 **`대결: 홍길동 (원 결재자: 김팀장)`** 형태로 명백하게 기재되어 책임 소재를 명확히 합니다.
* **중복 결재 방지**: 대결자가 이미 처리한 문서는 원 결재자가 중복으로 처리할 수 없으며, 반대로 원 결재자가 먼저 처리한 경우 대결자의 처리 권한도 자동으로 완료 처리됩니다.
* **관리자 직권 등록 지원**: 임직원의 급작스러운 사고나 장기 입원으로 본인이 직접 위임 설정을 할 수 없는 경우, **최고 관리자**가 직권으로 특정 임직원의 대결자를 등록하여 전사 업무 공백을 방지할 수 있습니다.

## 5. 실무 활용 팁

* **휴가 전날 사전 설정**: 장기 휴가나 출장 예정 시 휴가 출발 전날 미리 시작일과 종료일을 지정해 두면, 당일이 되었을 때 시스템이 알아서 대결 상태로 전환되므로 안심하고 자리를 비울 수 있습니다.
* **직무 유관자 지정**: 부서 예산 품의나 전문 기술 심사를 위해 가급적 동일 부서의 차순위자(예: 선임 차장이나 팀 내 부팀장)를 대결자로 지정하는 것을 권장합니다.
