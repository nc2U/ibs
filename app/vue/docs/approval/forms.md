# 기안 양식 안내 (17종 전용 폼)

IBS 전자결재 시스템은 업무 효율성과 데이터 정합성을 위해 각 업무 도메인별로 최적화된 **17종 전용 양식**을 지원합니다.

```
[17종 전용 양식]
 ├─ 1. 일반 / 공통 (2종)
 │    ├─ 일반 업무 품의서 (GENERAL)
 │    └─ 공문 발신 품의서 (OFFICIAL_LETTER)
 ├─ 2. 인사 / 근태 (5종)
 │    ├─ 휴가 / 연차 신청서 (LEAVE)
 │    ├─ 출장 신청서 (BUSINESS_TRIP)
 │    ├─ 연장 / 휴일근무 신청서 (OVERTIME)
 │    ├─ 인사 발령 품의서 (HR_APPOINTMENT)
 │    └─ 인사 관련 신청서 (HR_REQUEST)
 ├─ 3. 회계 / 자금 (4종)
 │    ├─ 구매 품의서 (PURCHASE)
 │    ├─ 지출 결의서 (EXPENSE)
 │    ├─ 경비 정산서 (EXPENSE_SETTLEMENT)
 │    └─ 선급금 / 가지급금 신청서 (ADVANCE)
 ├─ 4. 계약 / 법무 (3종)
 │    ├─ 계약 체결 품의서 (CONTRACT)
 │    ├─ 계약 변경 / 해지 품의서 (CONTRACT_CHANGE)
 │    └─ 법무 검토 요청서 (LEGAL_REVIEW)
 └─ 5. 사업 / 프로젝트 (3종)
      ├─ 신규 사업 검토서 (BUSINESS_REVIEW)
      ├─ 사업 추진 / 예산 승인서 (BUSINESS_APPROVAL)
      └─ 프로젝트 주요 의사결정서 (PROJECT_DECISION)
```

## 1. 일반 / 공통 카테고리

| 양식명 (`key`) | 주요 입력 항목 | 특징 |
| :--- | :--- | :--- |
| **일반 업무 품의서** (`GENERAL`) | 품의 목적, 주요 내용, 기대 효과, 소요 예산 | 회사 전반의 일반 업무 승인을 위한 표준 서식 |
| **공문 발신 품의서** (`OFFICIAL_LETTER`) | 수신처, 발신 명의, 시행일자, 공문 본문 | 대외 기관/거래처 발송 공문의 공식 승인 및 채번 연동 |

## 2. 인사 / 근태 카테고리

| 양식명 (`key`) | 주요 입력 항목 | 특징 |
| :--- | :--- | :--- |
| **휴가 / 연차 신청서** (`LEAVE`) | 휴가 구분(연차/반차/경조/병가), 기간, 차감 일수, 비상연락처 | 잔여 연차 자동 계산 연동 |
| **출장 신청서** (`BUSINESS_TRIP`) | 출장지, 출장 목적, 기간, 예상 여비 내역 | 숙박비, 일비, 교통비 산출 |
| **연장 / 휴일근무 신청서** (`OVERTIME`) | 근무 일시, 사전 승인 사유, 예상 근무 시간 | 주 52시간 근태 관리 연동 |
| **인사 발령 품의서** (`HR_APPOINTMENT`) | 대상자, 발령 구분(승진/전보/보직), 발령 부서/직책 | 승인 시 `StaffAssignment` 자동 반영 지원 |
| **인사 관련 신청서** (`HR_REQUEST`) | 신청 구분(증명서 발급/교육 신청/복리후생 지원 등) | 기타 인사 총무 요청 처리 |

## 3. 회계 / 자금 카테고리

| 양식명 (`key`) | 주요 입력 항목 | 특징 |
| :--- | :--- | :--- |
| **구매 품의서** (`PURCHASE`) | 품목명, 규격, 수량, 단가, 공급가액, 부가세, 구입 목적 | 품목별 소계 및 총액 자동 계산 |
| **지출 결의서** (`EXPENSE`) | 지출 계정, 지급 대상, 지급 기한, 입금 계좌정보, 증빙 목록 | 전표 및 회계 시스템 연동 |
| **경비 정산서** (`EXPENSE_SETTLEMENT`) | 영수증 일자, 사용처, 금액, 정산 사유, 법인카드 승인번호 | 출장 및 일상 경비 실비 정산 |
| **선급금 / 가지급금 신청서** (`ADVANCE`) | 신청 금액, 지급 목적, 정산 예정일자 | 자금 집행 전 선지급 승인 |

## 4. 계약 / 법무 카테고리

| 양식명 (`key`) | 주요 입력 항목 | 특징 |
| :--- | :--- | :--- |
| **계약 체결 품의서** (`CONTRACT`) | 계약 상대방, 계약 금액, 계약 기간, 주요 조항 요약 | 계약 체결 사전 의사결정 |
| **계약 변경 / 해지 품의서** (`CONTRACT_CHANGE`) | 원 계약 정보, 변경/해지 사유, 정산 조건 | 기 체결된 계약의 조건 변경 및 해지 |
| **법무 검토 요청서** (`LEGAL_REVIEW`) | 검토 대상 안건, 주요 법적 쟁점, 계약서 초안 첨부 | 사내외 변호사 및 법무팀 자문 검토 |

## 5. 사업 / 프로젝트 카테고리

| 양식명 (`key`) | 주요 입력 항목 | 특징 |
| :--- | :--- | :--- |
| **신규 사업 검토서** (`BUSINESS_REVIEW`) | 대상 사업지, 사업 개요, 수지 분석 요약, 예상 수익률 (IRR) | 사업 초기 타당성 검토 |
| **사업 추진 / 예산 승인서** (`BUSINESS_APPROVAL`) | 사업 실행 계획, 단계별 집행 예산, 이사회/경영진 의결 사항 | 대규모 자금 투입 및 인허가 추진 승인 |
| **프로젝트 주요 의사결정서** (`PROJECT_DECISION`) | 의사결정 배경, 복수 대안 비교표, 권고안, 리스크 평가 | 설계/시공사 선정, 분양가 책정 등 핵심 결정 |
