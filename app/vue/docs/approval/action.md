# 승인 / 반려 / 상신 회수

결재 진행 중 발생하는 각 결재 액션의 처리 기준과 절차를 안내합니다.

## 1. 결재 승인 (Approve)

현재 결재 순번에 해당하는 결재자는 문서의 내용과 첨부파일을 확인한 후 승인할 수 있습니다.

- **승인 의견 입력**: 승인 시 필요한 추가 코멘트를 선택적으로 남길 수 있습니다.
- **전자 서명 날인**: 승인이 완료되면 문서 타임라인 및 인쇄용 PDF의 결재란에 결재자의 전자 서명/도장 및 승인 일시가 자동으로 각인됩니다.
- **다음 단계 호출**: 승인 즉시 다음 순번 결재자에게 모바일 푸시 및 웹 알림이 전달됩니다.

## 2. 결재 반려 (Reject)

결재 내용의 보완이 필요하거나 부적합한 경우 문서를 반려할 수 있습니다.

- **반려 사유 입력 필수**: 결재자는 기안자가 수정·보완할 수 있도록 **반려 사유(의견)를 필수로 입력**해야 합니다.
- **결재선 즉시 중단**: 반려 시 후속 결재 단계는 모두 중단되며, 문서 상태가 `반려 (rejected)`로 전환됩니다.
- **기안자 알림**: 기안자에게 반려 사유가 포함된 푸시 알림이 발송되며, 기안자는 문서를 복사하거나 수정하여 재상신할 수 있습니다.

## 3. 기안 회수 / 상신 취소 (Cancel)

기안자가 상신 후 오탈자를 발견했거나 내용 수정이 필요한 경우 상신된 결재를 다시 회수하여 임시저장 상태로 되돌릴 수 있습니다.

### 회수 가능 조건
- **1차 결재자가 승인하기 전**: 기안자는 상세 화면에서 `[기안 회수]` 버튼을 눌러 언제든지 안전하게 문서를 회수할 수 있습니다.
- 회수 시 기존 결재선 단계는 초기화되며, 문서는 `임시저장 (draft)` 상태로 변경되어 내용을 수정한 후 다시 상신할 수 있습니다.

### 회수 불가 조건
- **1차 결재자가 이미 승인을 완료한 경우**: 결재 프로세스가 이미 시작되었으므로 기안자가 임의로 회수할 수 없으며, 결재자에게 반려를 요청해야 합니다.
- **최종 승인이 완료된 경우**: 법적 효력이 발생하고 채번된 문서는 회수할 수 없습니다.
