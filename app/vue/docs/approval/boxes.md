# 문서함 구분 및 검색

전자결재 메뉴의 각 문서함의 역할과 다차원 검색/필터링 기능을 안내합니다.

## 1. 전자결재 문서함 구성

| 문서함명 | 주요 대상 및 기준 | 권한 및 특징 |
| :--- | :--- | :--- |
| **결재 대기함** (`/approval/pending`) | 내가 현재 순번으로 결재해야 할 문서 (대리 결재 대상 포함) | 미결재 건수가 사이드바 배지에 실시간(Red Badge)으로 카운트됨 |
| **기안 문서함** (`/approval/drafted`) | 내가 작성한 모든 기안 문서 (임시저장, 진행중, 반려, 완료) | 임시저장 수정/삭제, 상신 취소(회수), 반려 건 복사 기안 |
| **결재 문서함** (`/approval/approved`) | 내가 결재선에 참여하여 최종 승인 완료된 문서 | 열람, 이력 확인 및 공식 PDF 다운로드/인쇄 |
| **전체 문서함** (`/approval/all`) | 내가 열람 권한(보안등급/참조자/부서공개)을 가진 회사 내 모든 결재 문서 | 전사/부서 공개 결재 문서 통합 검색 및 열람 |

## 2. 보안 등급별 열람 범위

전체 문서함 및 목록 조회 시 문서에 부여된 보안 등급에 따라 열람 권한이 자동 제어됩니다:

```
[1등급: 비공개]  ──▶ 기안자, 결재선 참여자, 지정된 참조자만 열람 가능
[2등급: 부서공개] ──▶ 기안자 소속 부서원 전체 열람 가능 (기본 설정)
[3등급: 전사공개] ──▶ 회사 전체 임직원 열람 가능
```

## 3. 다중 조건 검색 및 필터링

문서함 상단의 필터 툴바를 통해 대량의 문서 중에서 필요한 건을 신속하게 조회할 수 있습니다:

- **카테고리 / 문서 유형 필터**: 특정 업무(예: `인사/근태` $\to$ `휴가신청서`)만 선택 조회
- **진행 상태 필터**: `진행 중`, `최종 승인`, `반려`, `임시저장`
- **기간 검색**: 기안일자 기준 시작일 ~ 종료일 범위 지정
- **키워드 복합 검색**: 문서 번호, 기안자명, 문서 제목을 포괄하는 실시간 통합 검색
