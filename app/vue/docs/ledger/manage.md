# 거래 내역 관리

프로젝트에서 발생하는 모든 실제 입출금 내역을 기록하고, 이를 회계 계정 및 계약 정보와 연결하여 관리하는 핵심 화면입니다.

- **위치**: `회계 자금 관리 > 거래 내역 관리`

::: tip 📸 실제 화면 안내
![거래 내역 관리 화면](./images/manage.png)
*관리자 참고: 해당 화면의 실제 캡처 이미지를 `./images/manage.png` 경로에 등록해 주세요.*
:::

## 개요

통장상의 실제 거래 데이터(은행거래내역)를 등록하고, 각 거래가 회계상 어떤 의미(분류 내역)를 갖는지 정의합니다. 하나의 은행 입출금 건을 여러 개의 회계 계정으로 나누어 분개하는 1:N 분할 전표 처리를 지원하며, 분양 대금 수입이나 외주 용역비 등 특정 계정은 실제 분양 계약 정보와 연결하여 수납 장부 및 회계 장부의 정합성을 보장합니다.

```mermaid
flowchart LR
    A["1. 거래 정보 입력<br/>(일자·계좌·입출금액)"] --> B["2. 회계 계정 분할<br/>(1:N 분개·지출증빙)"]
    B --> C["3. 계약 정보 연동<br/>(분양수입·미수금 매칭)"]
    C --> D["4. 차액 검증 확인<br/>(은행 거래액 == 분류액 합계 ✅)"]
    D --> E["5. 최종 저장 및 장부 반영<br/>(정산 보호 및 이력 관리)"]
```

## 주요 기능

- **다차원 상세 필터링 및 검색**: 조회 기간, 계정과목(자산/부채/수본/수익/비용), 거래 계좌, 계약 정보 등 다양한 조건 검색
- **다수 거래 동시 일괄 입력**: 한 번의 등록 작업으로 여러 건의 독립된 입출금 거래를 행 단위로 신속하게 추가
- **1:N 분할 전표(Split Transaction) 지원**: 하나의 출금액을 여러 개의 회계 비목(예: 공사비 + 부가세대급금 등)으로 상세 분개
- **계약 및 계약자 필수 연동**: 분양 수입, 분담금 환급 등 계약 관련 계정 선택 시 계약자 선택 팝업을 연동하여 데이터 불일치 차단
- **스마트 분개 편의 기능**: 출금 시 이체 수수료(500원) 자동 분개 생성, 내부 계좌 간 이동 시 반대편 '대체(입금)' 거래 자동 제안
- **스마트 엑셀 템플릿 대량 업로드**: 대용량 거래 및 분할 전표를 사전에 검증하고 안전하게 불러오는 2단계 임포트 시스템

## 화면 구성 및 실무 가이드

### 1. 목록 제어 및 검색 필터

원하는 거래 내역을 신속하게 찾기 위한 조건 지정 영역입니다.

- **검색 조건**: 거래일자 범위, 입출금 구분(전체/입금/출금), 계정 분류 체계, 상세 계정과목, 거래 계좌, 거래처명 및 적요 키워드
- **운영비용(전도금) 포함 보기**: 체크 시 사업비 메인 계좌뿐만 아니라 프로젝트 운영비(전도금) 계좌의 지출 내역까지 통합하여 조회합니다.

### 2. 입출금 현황 목록

조회된 거래 내역을 표시하며, 각 행은 상단의 **'은행거래내역'**과 하단의 **'분류 내역(회계 분개)'**으로 나누어 표시됩니다.

- **은행거래내역 (통장 원장)**: 실제 통장에 찍힌 거래일자, 계좌명, 적요, 입금액/출금액 정보
- **분류 내역 (회계 장부)**: 회계상 적용된 계정과목, 거래처, 분류 금액, 지출 증빙 유형(세금계산서, 카드, 계산서, 간이영수증 등)
- **금액 일치 검증 표시기**:
  - **초록색 체크(✅)**: 은행 거래 금액과 하단 분류 내역 합계가 100% 일치하는 정상 상태
  - **노란색/붉은색 경고(⚠️)**: 양측 금액에 차액이 발생한 상태로, 차액 금액이 안내되며 추가 분개가 필요함을 알림

### 3. 거래 등록 및 수정 폼

새로운 입출금 내역을 생성하거나 기존 거래를 상세 수정하는 영역입니다.

- **은행 거래 행 추가**: 신규 등록 시 [행 추가] 버튼을 눌러 여러 건의 통장 거래를 순서대로 입력할 수 있습니다.
- **이체 수수료 자동 입력 버튼**: 출금 항목 옆의 수수료 아이콘을 클릭하면 설정된 이체 수수료(예: 500원) 분개 행이 자동으로 추가되어 오타와 누락을 방지합니다.
- **대체 거래 자동 감지**: 내부 통장 간 이동을 위해 '대체(출금)' 계정을 선택하면, 상대 계좌로 입금되는 '대체(입금)' 전표를 자동으로 추가 생성할지 묻는 스마트 팝업이 작동합니다.

## 📊 대량 엑셀 업로드 가이드 (Bulk Excel Import)

대량의 외주 용역비 집행, 공사 기성 지급, 다수 계약자의 일괄 수납 내역을 엑셀 템플릿을 통해 안전하게 일괄 등록할 수 있습니다.

### 1. 템플릿 다운로드 및 시트 구성

화면 우측 상단의 **[엑셀 템플릿 다운로드]** 버튼을 클릭하면 3개의 시트로 구성된 스마트 엑셀 서식이 다운로드됩니다.

1. **거래내역 대량입력 (메인 시트)**: 실제 통장 거래 및 회계 분개 데이터를 입력하는 시트입니다.
2. **작성안내 시트**: 그룹번호 작성 원리, 지출증빙 코드(세금계산서, 카드, 계산서, 현금영수증 등), 필수 주의사항이 안내되어 있습니다.
3. **참조목록 시트**: 현재 프로젝트에 등록된 **정확한 거래 계좌명**과 **회계 계정과목명**이 나열되어 있어, 오타 없이 복사하여 붙여넣을 수 있습니다.

### 2. 그룹번호(1:N 분할 전표) 작성 방법

하나의 은행 통장 거래를 여러 회계 계정으로 나누어 분개할 때는 **[그룹번호]**를 활용합니다.

- **단일 거래 (1:1 분개)**:
  - 1행: 그룹번호 `1`, 거래일자, 계좌, 적요, 출금 100만원 → 계정(공사비), 분류금액 100만원 입력
- **분할 거래 (1:N 분개)**:
  - 1행: 그룹번호 `2`, 거래일자, 계좌, 적요, 출금 150만원 → 계정A(공사비), 분류금액 100만원 입력
  - 2행: 그룹번호 `2`, **은행거래 정보는 빈칸** → 계정B(부가세), 분류금액 50만원 입력
  - *주의: 동일한 그룹번호에 속한 분류금액 합계(100만 + 50만)는 은행 출금액(150만)과 정확히 일치해야 합니다.*

### 3. 사전 검증 및 미리보기 (Bulk Upload Dialog)

작성한 엑셀 파일을 업로드하면 데이터베이스에 즉시 저장되지 않고 **사전 검증 미리보기 창**이 열립니다.

- **행 단위 정밀 검증**: 날짜 형식 오류, 미등록 계정명, 입출금액과 분류금액 불일치 건을 사전에 감지하여 붉은색 경고(✖)로 표시합니다.
- **정상 거래만 선별 반영**: 오류가 포함된 거래는 자동으로 제외하고, 정상 검증된 건만 폼에 안전하게 반영할 수 있습니다.
- **반영 방식 선택**:
  - `현재 입력 내용 대체`: 기존에 작성 중이던 폼 내용을 비우고 엑셀 데이터로 교체합니다.
  - `현재 입력 내용 뒤에 추가`: 기존 작성 중이던 거래 뒤에 이어서 추가합니다.

> [!TIP]
> **2단계 안전 저장 프로세스 (Pre-apply → Final Save)**
> 엑셀을 업로드하더라도 데이터베이스에 즉시 저장되지 않고 **화면 입력 폼으로 먼저 안전하게 로드**됩니다. 화면에서 최종 검토를 마친 후 상단의 **[저장/생성]** 버튼을 클릭해야 비로소 데이터베이스에 최종 기록되므로 데이터 오염 사고를 원천 방지합니다.

> [!WARNING]
> **1회 업로드 권장 상한선**
> 브라우저 메모리 및 렌더링 안정성을 위해 **1회 업로드 시 은행 거래 50건 / 회계 계정 200행 이하**로 나누어 등록하는 것을 권장합니다.

## 💡 실무 활용 팁 및 주의 사항

- **계정별 필수 정보 매칭**: 분양수입, 미수금, 미지급금 등 **계약 정보와 직접 연결되는 계정**을 선택하면 시스템이 자동으로 [계약 정보 선택] 창을 띄웁니다. 이를 통해 수납 관리 메뉴와 회계 관리 메뉴의 데이터가 완벽하게 일치하게 됩니다.
- **수정 제한 (정산 마감 보호)**: 최종 정산이 완료된 일자 이전의 거래나, 시스템에 등록된 후 일정 기간(기본 10일)이 경과한 과거 데이터는 임의 수정 및 삭제가 제한됩니다. 수정이 필요할 경우 관리자 권한을 가진 담당자에게 잠금 해제를 요청해야 합니다.
- **지출 증빙 코드 관리**: 세금계산서, 계산서, 신용카드 영수증 등 적격 증빙 유형을 빠짐없이 선택해 두면 부가세 신고 및 회계 결산 감사 시 증빙 누락을 쉽게 추적할 수 있습니다.
