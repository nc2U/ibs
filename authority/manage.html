권한 설정 관리 ​

시스템을 이용하는 사용자별로 프로젝트 접근 권한을 관리하고, 각 부동산 개발 프로젝트별 비즈니스 데이터 처리 역할 (Role)을 지정하는 관리자 전용 페이지입니다.

  • 위치: 관리자 메뉴얼 > 권한 설정 관리

1. 개요 ​

회사의 현장 조직 구조와 프로젝트 담당 업무에 맞춰 사용자별 비즈니스 권한을 체계적으로 관리합니다. 사용자를 선택한 후, 각 부동산 개발 프로젝트별로 부여할 비즈니스 역할 ([ibs_global] 카테고리 역할) 을 체크박스로 손쉽게 할당하거나 해제할 수 있습니다.

2. 주요 기능 ​

  • 사용자 선택 및 권한 확인: 등록된 전체 사용자 중 대상을 선택하여 개별 프로젝트별로 부여된 역할 상태를 실시간으로 조회하고 수정할 수 있습니다.
  • 신규 사용자 직접 생성: 업무 관리자 (workManager) 권한을 가진 사용자는 [사용자 생성] 버튼을 통해 새 계정을 등록할 수 있습니다.
  • 안전한 임의 패스워드 생성: 사용자 생성 시 암호학적으로 안전한 8자리 임시 비밀번호를 자동 생성할 수 있습니다.
  • 알림 메일 및 패스워드 재설정 링크 발송: 신규 생성 사용자에게 계정 등록 안내 메일을 발송하고, 패스워드 재설정 링크 (만료 시간 지정 가능) 또는 임시 비밀번호를 포함할 수 있습니다.
  • 프로젝트별 담당 권한 매핑: 활성화된 부동산 개발 프로젝트별로 비즈니스 데이터 (ibs_global 카테고리) 역할을 체크박스 클릭으로 즉시 할당/수정/삭제 (멤버십 추가 및 탈퇴)할 수 있습니다.

3. 화면 구성 및 사용 방법 ​

3.1 사용자 선택 영역 (User Select) ​

권한을 조회하고 설정할 대상을 지정하는 영역입니다.

  • 사용자 선택 드롭다운: 전체 사용자 목록에서 권한을 변경할 대상을 검색하여 선택합니다.
  • 사용자 생성 버튼: 업무 관리자 (workManager)인 경우 우측 상단에 [사용자 생성] 버튼이 노출됩니다.

3.2 신규 사용자 생성 모달 (Add User Modal) ​

시스템에 새로운 사용자를 등록하고 초기 접속 정보를 발송합니다.

  1. 계정 정보 입력: 아이디, 이메일, 비밀번호를 입력합니다.
  2. 임의 패스워드 생성: [임의 패스워드 생성] 버튼을 클릭하면 보안 랜덤 비밀번호가 자동 생성되며 [적용]을 눌러 바로 사용할 수 있습니다.
  3. 알림 메일 발송 설정:
    • 패스워드 재설정 링크 포함: 링크 만료 시간 (1~24시간)을 지정하여 보안 비밀번호 재설정 이메일을 보냅니다.
    • 사용자 패스워드 포함: 생성된 임시 비밀번호를 이메일에 직접 포함하여 안내합니다.

3.3 프로젝트별 담당 권한 설정 영역 (Project Business Permissions) ​

선택된 사용자의 현장별 비즈니스 데이터 처리 역할을 할당하는 영역입니다.

  • 프로젝트 카드 목록: 현재 운영 중인 부동산 개발 프로젝트 (type='2', status='1')가 목록으로 표시됩니다.
    • 비공개 상태의 프로젝트는 배지가 함께 표시됩니다.
  • 비즈니스 역할 (ibs_global) 체크박스:
    • 프로젝트 카드의 체크박스를 선택하면 해당 사용자에게 프로젝트 멤버십이 생성되고 해당 비즈니스 역할 (예: 분양 계약 관리, 대금 수납 관리, 현장 회계 관리 등)이 부여됩니다.
    • 체크박스를 해제하면 역할이 제거되며, 부여된 역할이 0개가 되면 해당 프로젝트 멤버십에서 자동 탈퇴 처리됩니다.

💡 주요 관리 포인트 ​

프로젝트 기반 행 단위 보안 (Row-Level Security)

IBS 시스템은 프로젝트 멤버십 및 할당된 비즈니스 역할 (Role)을 기준으로 비즈니스 데이터 (계약, 수납, 장부, 분양 유닛, 현장 예산 등)의 조회 및 수정 권한을 백엔드 DB 레벨에서 엄격히 제어합니다.

1. 최소 권한 부여의 원칙 ​

데이터 보안을 위해 사용자에게는 실제 담당하는 현장 프로젝트의 필요한 역할만 부여할 것을 권장합니다.

2. 비공개 프로젝트 접근 제어 ​

비공개 표시가 지정된 프로젝트는 해당 프로젝트의 멤버로 등록된 사용자만 데이터를 조회하고 관리할 수 있습니다. 비멤버 직원의 경우 메뉴 및 목록에서 해당 비공개 프로젝트의 리소스가 은폐됩니다.

3. 사용자 계정 메일 알림 활용 ​

신규 사용자 생성 시 [패스워드 재설정 링크 포함] 옵션을 사용하는 것이 가장 안전합니다. 사용자가 수신된 이메일의 링크를 통해 본인의 비밀번호를 직접 설정하도록 안내하십시오.
