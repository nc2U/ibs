권한 설정 관리 ​

시스템을 이용하는 사용자별로 프로젝트 접근 권한을 관리하고, 각 부동산 개발 프로젝트별 비즈니스 데이터 처리 역할(Role)을 지정하는 관리자 전용 화면입니다.

  • 위치: 환경설정 > 권한 설정 관리

📸 실제 화면 안내

관리자 참고: 해당 화면의 실제 캡처 이미지를 ./images/manage.png 경로에 등록해 주세요.

개요 ​

회사의 조직 구조와 프로젝트 담당 업무에 맞춰 사용자별 비즈니스 권한을 체계적으로 통제합니다. 사용자를 선택한 후, 각 부동산 개발 프로젝트별로 부여할 프로젝트 비즈니스 역할(ibs_pr_manage 카테고리 역할)을 체크박스로 손쉽게 할당하거나 해제할 수 있으며, 신규 직원에 대한 계정 생성 및 보안 초기 접속 메일 발송을 지원합니다.

주요 기능 ​

  • 사용자 선택 및 권한 조회: 등록된 전체 사용자 중 대상을 선택하여 개별 프로젝트별로 부여된 비즈니스 역할 현황을 실시간 확인
  • 신규 사용자 즉시 생성: 업무 관리자(workManager) 권한을 가진 관리자는 [사용자 생성] 버튼을 통해 새 계정을 시스템에 직접 등록
  • 암호학적 임의 패스워드 생성: 사용자 생성 시 보안 규칙을 만족하는 8자리 임시 비밀번호 자동 생성
  • 보안 초대 메일 발송: 신규 사용자에게 계정 등록 안내 메일을 발송하며, 패스워드 재설정 링크(만료 시간 1~24시간 지정) 또는 임시 비밀번호 포함 옵션 제공
  • 프로젝트별 비즈니스 역할(ibs_pr_manage) 매핑: 운영 중인 부동산 개발 프로젝트별로 계약, 수납, 회계 장부, 유닛 관리 등 실무 역할을 체크박스 클릭으로 즉시 할당/회수
  • 원클릭 프로젝트 멤버십 동기화: 프로젝트 카드 내 역할을 1개 이상 체크하면 해당 프로젝트의 멤버십이 자동 생성되고, 모든 역할을 해제하면 멤버십에서 자동 제외

화면 구성 및 실무 가이드 ​

1. 사용자 선택 영역 (User Select) ​

권한을 조회하고 변경할 대상 사용자를 지정하는 영역입니다.

  • 사용자 선택 드롭다운: 시스템에 등록된 전체 사용자 중 권한을 설정할 임직원을 검색하여 선택합니다.
  • [사용자 생성] 버튼: 업무 관리자(workManager) 권한자에게만 상단 우측에 노출되며, 신규 계정 등록 모달을 호출합니다.

2. 신규 사용자 생성 모달 (Add User Modal) ​

새로운 직원을 시스템에 등록하고 초기 접속 안내를 진행합니다.

  1. 기본 계정 정보 입력: 로그인 아이디(영문/숫자), 공식 업무 이메일, 초기 비밀번호를 입력합니다.
  2. 임의 패스워드 자동 생성: [임의 패스워드 생성] 버튼을 클릭하면 난수화된 안전한 임시 비밀번호가 자동 생성되며, [적용]을 누르면 비밀번호 입력란에 자동 반영됩니다.
  3. 알림 메일 발송 옵션:
    • 패스워드 재설정 링크 포함 (권장): 링크 유효 시간(1~24시간)을 지정하여 보안 비밀번호 재설정 이메일을 보냅니다. 사용자가 직접 안전하게 비밀번호를 등록할 수 있습니다.
    • 사용자 패스워드 포함: 생성된 임시 비밀번호를 이메일 본문에 직접 기재하여 안내합니다.

3. 프로젝트별 담당 권한 설정 영역 (Project Business Permissions) ​

선택된 사용자의 사업지별 비즈니스 데이터 처리 역할을 지정합니다.

  • 프로젝트 카드 목록: 현재 활성화되어 운영 중인 부동산 개발 프로젝트들이 카드 형태로 나열됩니다.
    • 비공개로 운영되는 사업지는 카드 우측 상단에 🔒 비공개 배지가 함께 표시됩니다.
  • 비즈니스 역할 (ibs_pr_manage) 체크박스:
    • 카드 내에서 해당 직원이 담당할 업무(예: 분양 계약 관리, 대금 수납 관리, 프로젝트 회계 관리 등) 체크박스를 선택하면, 즉시 해당 프로젝트 멤버십이 생성되고 권한이 활성화됩니다.
    • 모든 체크박스를 해제하면 해당 프로젝트 멤버십에서 자동으로 탈퇴 처리되어 불필요한 데이터 노출을 원천 방지합니다.

💡 실무 관리 포인트 ​

NOTE

프로젝트 기반 행 단위 데이터 보안 (Row-Level Security) 시스템은 프로젝트 멤버십 및 할당된 비즈니스 역할(Role)을 기준으로 계약자 개인정보, 수납 내역, 지출 장부, 예산 등 핵심 비즈니스 데이터의 조회 및 수정 범위를 데이터베이스 레벨에서 엄격하게 통제합니다.

  • 최소 권한 부여 원칙 (Principle of Least Privilege): 데이터 보안 및 개인정보 보호를 위해 임직원에게는 현재 실제로 담당하는 프로젝트와 업무에 꼭 필요한 역할만 최소한으로 부여하는 것을 권장합니다.
  • 비공개 프로젝트 보안 격리: 🔒 비공개 설정된 프로젝트는 해당 프로젝트 멤버로 명시적으로 등록된 사용자에게만 데이터와 메뉴가 노출됩니다. 멤버가 아닌 일반 직원의 화면에서는 해당 프로젝트의 존재 자체가 은폐됩니다.
  • 보안 초대 메일 링크 활용: 신규 계정 발급 시 임시 비밀번호를 평문으로 메일에 적어 보내는 것보다, [패스워드 재설정 링크 포함] 방식을 사용하는 것이 정보 보안상 가장 안전합니다.
